# 게임 브리프

> 이 파일 하나에 게임 기획을 모았습니다. 앞쪽은 한눈에 보는 요약이고, 뒤쪽 1~4부는 예전 `docs/01`~`04` 문서의 본문을 그대로 옮긴 것입니다 (2026-11-12 통합).
> "확정"은 연님이 정한 것, "제안"은 Claude가 채운 것입니다. 구현 계획과 작업 기록은 `docs/05-build-plan.md` 에 따로 있습니다.

## 요약

### 컨셉

인터넷에서 2009년에 개발이 멈춘 미완성 쯔꾸르 게임 파일을 내려받아 실행한 주인공이, 한밤중 학교에서 깨어나 10년 넘게 갇혀 있던 소녀 윤하와 함께 학교를 탈출하는 공포 쯔꾸르풍 웹게임.

- 장르: 탑뷰 픽셀 공포 탈출 어드벤처 (쯔꾸르풍)
- 플랫폼: 웹 브라우저
- 무대: 학교 하나 (본관, 특별동, 체육 구역, 지하, 옥상)
- 목표 플레이타임: 처음 플레이 기준 120분 내외
- 제목: 미정. 그때까지 작중 게임 이름 `비현실`을 씀

### 분위기

- 한밤중의 학교. 칠판 위 시계는 12시를 가리킨 채 멈춰 있다
- 지시하는 관리자나 시스템 메시지는 없다. 진행은 힌트로만: 낙서, 쪽지, 학교 게시물, 윤하의 말, 불이 켜지거나 문이 열리는 환경 변화
- 윤하: 서글서글하고 장난기가 많으며 겁이 없고 요망함. 무서운 곳에서 혼자 태연한 아이가 옆에 있다는 것이 이 게임의 온도
- "고르지 말고 직접 하라"는 함정. 학교 규칙을 따라야 할 때와 어겨야 할 때가 섞여 있다
- 죽음은 가깝지만 억울하지 않게. 판정은 넉넉하게, 힌트를 봐도 불이익 없음

### 첫 1분

1. 화면 전체가 주인공의 컴퓨터 바탕화면. 마우스로 직접 조작한다
2. 인터넷 아이콘만 깜빡인다. 괴담 게시판에서 2009년 개발이 중단된 미완성 쯔꾸르 게임 글을 발견한다. 첨부 파일 `비현실.exe.zip`
3. 취소를 누르면 "파일을 받으시겠습니까?", 다시 누르면 "왜 안 받아요?", 세 번째에는 플레이어의 이름을 부른다. 그 뒤로는 다운로드 말고는 누를 수 없다
4. 플레이어가 "내가 이걸 받았다"는 찝찝함을 느끼게 하는 것이 목적
5. 화면이 꺼지고, 한밤중 교실 책상에서 깨어난다

### 핵심 재미

- **학교를 읽어서 푸는 퍼즐**: 칠판 낙서와 시간표를 맞춰 사물함을 고르고, 거짓말쟁이를 추리한 뒤 "고르지 않고 직접" 찌른다
- **윤하와 둘이서**: 둘이 동시에 열어야 열리는 문, 유리벽 너머 윤하의 방과 마주보게 맞추는 방, 윤하가 내민 손
- **숨고 도망치기**: 경비와 붉은 형체. 달리면 소리가 나고, 숨으면 숨을 참아야 한다
- **모으는 이야기**: 학교 곳곳의 장기로 인체 모형을 완성하고, 찢겨 흩어진 <제물의 일기장>으로 학교의 사정을 알게 된다
- **일기장과 잉크**: 잉크는 적게 준다. 어디서 일기를 쓸지가 선택이 된다

### 나중으로 미룬 것

- <제물의 일기장> 2~4장 문구. 연님이 직접 채움 (`data/notes.json`)
- 게임 제목, 엔딩 크레딧 내용
- 교무실 1~8의 실제 배치 반영
- 공개 배포. 1~4장 흐름이 웹소설 『공포 쯔꾸르 생존기』와 많이 겹쳐서, 배포한다면 겹치는 장면을 더 바꿔야 함

### 아직 비어 있는 결정

- 인벤토리 칸 수, 피 차오르는 제한 시간(60초) 같은 수치는 제안값으로 구현되어 있음. 플레이해 보고 조정

## 1부. 개요와 공통 시스템

### 한 줄 요약

인터넷에서 2009년에 개발이 멈춘 미완성 쯔꾸르 게임 파일을 내려받아 실행한 주인공이, 한밤중 학교에서 깨어나 10년 넘게 갇혀 있던 소녀 윤하와 함께 학교를 탈출하는 공포 쯔꾸르풍 웹게임.

- 장르: 탑뷰 픽셀 공포 탈출 어드벤처 (쯔꾸르풍)
- 플랫폼: 웹 브라우저 (HTML + Canvas + JavaScript)
- 목표 플레이타임: 처음 플레이 기준 120분 내외
- 무대: 학교 하나 (본관, 특별동, 체육 구역, 지하, 옥상)

표기 규칙: "확정"은 연님이 정한 것, "제안"은 Claude가 채운 것으로 연님 확인이 필요한 것.

### 인물

| 인물 | 설정 | 상태 |
|---|---|---|
| 주인공 | 고등학생. 공포게임을 즐겨 보는 평범한 학생. 이름은 플레이어 입력 | 이름 방식 미정 |
| 윤하 | 10년 넘게 학교에 갇혀 있던 학생. 서글서글하고 장난기가 많으며 겁이 없고 요망함 | 확정 |
| 경비 | 밤의 학교를 순찰하는 존재. 열쇠 꾸러미를 허리에 참 | 확정 (외형 세부는 제안) |
| 붉은 형체 | 실험실 전시장 안에 있던 붉은 피부의 사람 형태. 매우 느림 | 확정 |
| 그 밖의 괴이 | 촉수, 졸업사진 속 존재 등 | 제안 |

### 공통 시스템

#### 상태창 (확정)

- 열기: 키보드 `Tab` (모바일은 화면 우측 상단 버튼)
- 표시: 정신력 게이지, 현재 목표 한 줄, 보유 잉크 개수, 동행 중인 인물
- 관리자나 시스템 메시지로 지시하는 존재는 없음. 진행은 힌트로만

#### 인벤토리 (확정)

- 열기: 키보드 `I`
- 칸 수 제한: 8칸 (제안)
- 조사(설명 읽기), 사용, 조합
- 일기장은 칸을 차지하지 않는 고정 아이템
- 장기 모형은 "장기 주머니"라는 별도 칸에 모임 (제안. 인체 모형 퍼즐용)

#### 체크포인트: 일기장과 잉크 (확정)

- 일기장: 시작 교실 다음 교실에서 획득. 끝까지 사용
- 잉크: 특정 장소에 놓인 일회성 소모품. 상한 없음. 적게 줌
- 일기장 + 잉크 1개 = 그 자리 저장
- 일기를 한 번도 안 쓰고 죽으면 첫 교실부터 다시 시작
- 죽으면 마지막으로 일기를 쓴 곳에서 다시 시작 (제안)
- 일기를 쓸 수 있는 장소: 어디서나 (제안. 단, 추격 중에는 불가)
- 일기장에는 현재 목표, 단서 정리, 단계별 힌트, 주운 쪽지 모음이 함께 들어감

#### 정신력 (제안)

- 0~100. 공포 이벤트, 어둠 속 장시간 체류, 괴이와 눈 마주침으로 감소
- 40 이하: 화면 가장자리 어두워짐, 환청 발소리
- 20 이하: 가짜 낙서와 가짜 아이템이 보임
- 0: 기절 → 사망 처리
- 회복: 사탕(아이템), 불 켜진 방에서 쉬기, 윤하와 대화 이벤트

#### 힌트 진행 (확정)

- 힌트원: 낙서, 쪽지, 학교 게시물, 윤하의 말, 환경 변화(불이 켜지거나 문이 열림)
- 일기장의 "단서 정리"에서 막힌 퍼즐의 힌트를 단계별로 볼 수 있음: 1단계 방향 → 2단계 위치 → 3단계 정답
- 힌트를 봐도 불이익 없음. 엔딩 화면 기록에만 표시

#### 숨기 (제안)

- 숨을 수 있는 곳: 책상 밑, 사물함, 커튼 뒤, 청소용 카트 뒤, 매트 더미
- 숨은 상태에서 괴이가 가까이 오면 "숨 참기": 버튼을 누르고 있다가 괴이가 멀어지면 뗌
- 같은 장소에 3번 연속 숨으면 다음부터 괴이가 그곳을 먼저 확인

#### 추격 (제안)

- 괴이는 순찰 → 소리 조사 → 추격 → 놓치면 수색 후 복귀
- 달리기는 소리를 냄. 걷기는 조용함
- 추격 중에는 일기장 사용 불가, 인벤토리 열면 시간이 멈추지 않음

#### 접근성 옵션 (제안)

- 타이밍 입력 판정 범위 넓히기 (숨 참기, 연타, 게이지 멈추기)
- 연타 입력을 "길게 누르기"로 바꾸기
- 깜짝 연출 강도, 화면 흔들림 끄기, 볼륨 분리 조절

### 이야기의 뼈대 (제안)

5장 이후는 연님이 아직 정하지 않은 부분이라, 지금까지 확정된 떡밥(10년 넘게 갇힌 윤하, 제물의 일기장, 학교 터가 예전 공동묘지, 인체 모형)을 하나로 묶는 안을 제안합니다.

- 학교는 예전 공동묘지 터 위에 세워졌고, 학교는 일정한 때마다 "제물"을 붙잡아 둠
- <제물의 일기장>을 쓴 학생은 수십 년 전 담력 체험을 왔다가 첫 제물이 된 사람. 일기장은 여러 장으로 찢겨 학교 곳곳에 흩어져 있음
- 윤하도 10년 넘게 전 같은 방식으로 붙잡힌 제물
- 학교는 제물 한 명을 붙잡아 두는 대신 나머지를 내보내줌. 그래서 탈출하려면 누군가 대신 남아야 함
- 인체 모형을 장기까지 완성하면 "대역"이 되어 한 사람 몫을 대신할 수 있음
- 하지만 대역은 하나뿐. 마지막에 누가 나갈지 선택해야 함
- 윤하가 요망하게 구는 이유: 처음부터 이 규칙을 알고 있었고, 주인공을 이용해 자기가 나가려 했던 것. 그러다 함께 다니며 마음이 바뀜

### 인트로 (확정, 5분)

1. 화면 전체가 주인공의 컴퓨터 바탕화면. 마우스로 직접 조작
2. 바탕화면 아이콘은 대부분 반응이 없거나 빈 폴더. 인터넷 아이콘만 깜빡이며 열도록 유도
3. 괴담 게시판에서 2009년 개발이 중단된 미완성 쯔꾸르 게임 글을 발견. 첨부 파일 `비현실.exe.zip`
4. 다운로드 강제 연출 (M0)

### 1장. 깨어남 (8분)

### 5장. 별실: 졸업사진과 특수 잉크 (확정, 12분)

연님 손글씨 기획(2026-11-12)과 답변을 옮긴 것입니다. 원문은 `docs/reference/ch5-byeolsil-notes.md`. 규칙은 M9.

1. 환풍구 끝은 별실로 이어짐. 주인공은 A3 칸으로 나옴. 방 안에는 삼각대 카메라(C1), 목 없는 시체(E2), 시체의 머리(C3), 간(C8), 특수 잉크(C2)
2. C2의 특수 잉크를 주우면 윤하가 장난으로 카메라로 주인공을 찍음
3. 주인공이 A3으로 돌아가면 <졸업사진 주의사항>의 찢어진 윗부분을 얻고 카메라가 움직이기 시작 (M9)
4. 주인공과 윤하가 한 칸 움직일 때마다 카메라도 한 칸 움직임. 카메라와 같은 칸에 있는 것은 찍힘. 카메라가 C3에 오면 시체의 머리가 찍혀 사라짐
5. 카메라가 D7에 오면 주인공이 자기가 희생하겠다고 하고 윤하가 말림. 카메라가 주인공을 찍고 졸업사진이 출력됨
6. 찍힌 주인공은 졸업사진 속 흰 방에 갇힘 (의자에 묶여 움직일 수 없음, 벽의 얼굴 모양 구멍으로 바깥의 윤하가 보임). 여기서 특수 잉크를 보여 주며 약관 조항을 다시 떠올림
7. 윤하가 <졸업사진 주의사항>의 나머지 부분을 찾아내 졸업사진을 찢음. 주인공에게는 흰 방이 같이 찢어져 보이고, 사진 밖으로 풀려남
8. 얻는 것: 특수 잉크, 간(장기), <졸업사진 주의사항>

약관 문구와 주의사항 윗부분 문구는 연님이 준 참고 사진대로 넣었습니다 (`data/notes.json`). 주의사항 아랫부분 문구는 Claude 제안. <제물의 일기장> 2장을 어디서 얻는지는 미정.

- 화폐: 학교 곳곳(책상 서랍, 자판기 아래, 소파 틈)에서 줍는 동전
- 상품과 가격 (예시)
  - 사탕 (정신력 +20): 2개
  - 건전지 (손전등 충전): 3개
  - 붕대 (추격 중 잡혔을 때 1회 버티기): 5개
  - 냉장고 속 위(장기): 4개 (필수 구매)
- 규칙: 계산대에 아무도 없음. 값을 내지 않고 들고 나가면 셔터가 내려오고 어둠 속 무언가가 다가옴 → 물건을 돌려놓으면 셔터가 올라감
- 매점은 장이 바뀔 때마다 진열이 조금씩 바뀜

### M11. 진정제 조제 (제안)

- 단서: 보건 일지 "잠 못 드는 아이에겐 흰 병 하나, 파란 병 하나. 빨간 병은 절대 섞지 말 것"
- 할 일: 약장의 병 4개(흰, 파랑, 빨강, 초록) 중 골라 비커에 넣기
- 정답: 흰 + 파랑 → 진정제 (괴이를 5초 멈추는 아이템, 1회용)
- 실패: 빨강을 섞으면 비커가 끓어오르며 연기, 정신력 -10. 초록은 아무 효과 없음
- 함께 얻는 것: 간(장기, 보건실 침대 커튼 뒤), 잉크

### M12. 출석 호명 (제안)

- 장소: 교무실1에서 처음 등장, 교무실6에서 변형. 다른 교무실(2~5, 7, 8)은 단서·아이템 방 (교무실8은 위치 미정)
- 규칙
  - 담임 자리의 형체가 출석부를 펴고 이름 10개를 부름
  - 이름마다 3초 안에 "네" 또는 "침묵" 선택
  - 플레이어 이름 → "네"
  - 윤하 이름 → 윤하가 대신 대답 (플레이어는 침묵)
  - <제물의 일기장> 속 이름(경균, 수정 등) → 침묵
  - 모르는 이름 → 침묵
- 실패: 한 번 틀릴 때마다 정신력 -15. 3번 틀리면 출석부에서 이름이 지워지며 사망
- 교무실6 변형: 이름을 거꾸로 읽어서 부름 ("하윤" 등). 귀로 듣고 판단해야 함
- 얻는 것: 신장(교무실1, 교무실6 각각)

### M13. 방송실 (제안)

- 퍼즐: 녹음테이프 4개를 라벨 날짜순으로 데크에 넣으면 <제물의 일기장> 3장이 목소리로 재생
- 유인: 방송 버튼을 누르면 30초간 교내 방송 소음 → 경비가 소리 나는 층으로 이동. 그동안 특별동 위층 이동이 안전
- 대가: 방송이 끝나면 경비가 방송실로 옴. 30초 안에 빠져나가야 함
- 얻는 것: 잉크, 테이프 (수집품)

**<제물의 일기장> 3장** (제안)

### M14. 화면 속 게임 (제안)

- 퍼즐: 모니터 속 작은 주인공을 키보드로 움직여 화면 속 컴퓨터실의 스위치를 누르면, 현실의 준비실 문이 열림
- 메타 연출: 성공 직후 가짜 크래시 화면(오류창) 3초 → 다시 돌아오면 저장 일기의 시간 표기가 이상하게 바뀌어 있음 (실제 저장은 그대로)

### M15. 피아노가 멈추면 (제안)

- 음악 준비실 건반 퍼즐: 칠판 악보에 숫자로 적힌 음 "1 3 5 8" → 도 미 솔 (높은)도 입력
