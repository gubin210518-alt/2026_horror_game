# 04. 연님이 정해줄 것과 필요한 자료

## 정해야 할 것

### 이야기
- [ ] 5장 이후 흐름: `02-storyline.md`의 제안(학교는 제물 한 명만 붙잡아 두고, 인체 모형이 대역이 된다)을 쓸지, 다른 방향으로 갈지
- [ ] 최종 엔딩 구성: 제안한 5개 엔딩(진, 노말 2, 배드 2)을 쓸지
- [ ] <제물의 일기장> 2~4장: 제안 문구를 쓸지, 직접 쓸지
- [ ] 주인공 이름: 고정할지, 플레이어 입력으로 할지
- [ ] 윤하가 숨기는 비밀: "처음엔 주인공을 이용해 자기가 나가려 했다"는 제안을 쓸지

### 장소
- [ ] 비품실 안에 둘 것 (제안: 손전등, 도서관 열쇠, 학교 안내도)
- [ ] 교무실8의 위치와 역할
- [ ] 실제 학교 교무실 1~8 배치 (알려주면 지도에 반영)
- [ ] 졸업사진 촬영 장소를 강당으로 할지

### 시스템
- [ ] 죽으면 마지막 일기 위치에서 재시작하는 게 맞는지
- [ ] 일기를 아무 데서나 쓸 수 있게 할지, 책상 있는 곳만 할지
- [ ] 정신력 게이지를 넣을지
- [ ] 인벤토리 칸 수 (제안: 8칸)
- [ ] 가란델가 퍼즐의 피 차오르는 제한 시간 (제안: 60초)
- [ ] 경비 열쇠 장면을 자동 연출로 할지, 버튼 입력으로 할지
- [ ] <읽으면 죽는 책>의 쓰임 (제안: 진엔딩 열쇠)

## 필요한 자료

### 이미지 (나노바나나 또는 Higgsfield로 제작)
- [ ] 캐릭터 걷기 시트: 주인공, 윤하, 경비, 붉은 형체
- [ ] 배경: 교실, 복도, 미술실, 비품실, 도서관(높은 책장), 비밀서고 대칭 방 2개, 과학실, 실험실, 환풍구 내부, 강당
- [ ] 그림: <가란델가의 자매들> 액자 (자매 4명이 구분되게)
- [ ] 오브젝트: 사물함, 액자, 물감칼, 잉크병, 일기장, 장기 9종, 황산병, 인체 모형, 졸업사진 세트
- [ ] 대화창 초상화: 주인공, 윤하 (기본, 웃음, 놀람, 장난, 진지)

### 소리
- [ ] 배경음: 교실(정적), 추격, 미술실 피 차오를 때, 엔딩
- [ ] 효과음: 발소리, 문 잠김, 셔터, 유리 깨짐, 촉수, 피아노, 공 튀기는 소리
- [ ] 무료 효과음 출처를 정해야 함 (출처 표기 조건 확인 필요)

### 기타
- [ ] 게임 제목 확정
- [ ] 엔딩 크레딧에 넣을 내용
