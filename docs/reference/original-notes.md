- 출처: 나무위키 「공포 쯔꾸르 생존기」 및 관련 하위 문서 (CC BY-NC-SA 2.0 KR)
- 원작: 파급효과 작가의 웹소설, 문피아 연재, 본편 193화 완결, 외전 포함 201화

## 2. 원작의 게임 시스템

**상태창**
- 튜토리얼(교실 탈출) 완료 보상으로 해금
- "상태창"이라고 말하면 열림
- 항목: 이름, 나이, 칭호, 특성, 특수 능력
- 주인공의 특성은 "침착" (공포에 내성이 있어 금방 침착을 되찾지만, 한계를 넘은 공포 앞에서는 소용없음)

**퀘스트**
- 튜토리얼: 제한 시간(10분) 안에 교실 탈출, 실패 시 사망
- 학교 탈출: 해가 뜨기 전에 학교를 탈출, 보상은 괴담코인

**체크포인트**
- 사망 시 사망 메시지 후 체크포인트에서 다시 시작
- 첫 체크포인트는 교실 (공책의 시간 표기, 12시 시계, 튜토리얼 메시지가 재현된 상태)

**상호작용**
- 사물을 조사하면 상황 설명 문구
- 아이템 획득 메시지, "인벤토리"라고 말하면 보유 아이템 창
- 아이템 사용 전 확인 메시지

**일기장(세이브)**
- 체크포인트와 별개인 기록(세이브) 기능
- 교실에서 일기장 획득. 첫 페이지에 붉은 글씨로 시간 표기
- 잉크가 있어야 기록 가능
- 기록하면 페이지가 붉게 물들고 다음 페이지에 시간 표기
- 잉크: 붉은색 소모 아이템. 첫 획득처는 교무실 입구의 분실물 보관함

## 3. 원작의 초반 기믹 (캡처 범위)

**교실**
- 앞문·뒷문이 자물쇠로 잠겨 있음. 밖에서 열어주지 않으면 나갈 수 없음. 복도와 창밖은 어둡고, 벽시계는 12시 정각
- 뒤편 사물함 중 하나만 새빨간 색이고 자물쇠로 잠겨 있음
- 뒷문 자물쇠는 4자리 숫자 입력식
- 숫자 단서: 쪽지에 적힌 '0134'. 그대로 자물쇠에 입력하면 열리지 않음
- 리코더: 교실 책상 서랍에서 획득. 겉면 명찰에 진다연의 학번과 이름이 적혀 있음
- 학급 게시판 공지문: 리코더 수행평가 안내 (다음 주 목요일 음악 시간, 4교시 11:20 시작 등). 뒷면에 리코더 운지법 표가 있고, 구멍을 막는 표시(○/●)와 숫자(0~7)를 씀
- 해법: '0134'를 비밀번호가 아니라 리코더 운지 단서로 해석. 해당 구멍을 막고 리코더를 불면 뒷문이 열림

**복도**
- EXIT 비상구 표지판 불빛이 길잡이 역할
- 중앙현관 사용 금지 안내 팻말 (몰래 쓰다 적발되면 벌점이라는 내용)
- 경비 추적 트리거: 팻말과 중앙현관 경계선을 넘는 순간, 복도 끝에서 경비가 팔다리를 꺾으며 비정상적인 속도로 달려옴

**중앙현관**
- 출입문 손잡이가 쇠사슬로 감겨 있어 열리지 않음. 주인공은 절단기가 필요하다고 추측
- 청소도구함: 구석에 방치된 먼지투성이 도구함. 열 때 삐걱 소리와 먼지로 기침이 남. 경비를 피해 숨는 곳
  - 안에서 자세만 바꿔도 삐걱 소리가 나고, 소음이 나면 경비가 바로 반응
  - 기침으로 위치가 들키면 발각되어 사망
- 건물 안내(지도): 중앙현관 벽에 본관 구조가 간략히 표시. 주인공은 이를 보고 창고가 지하에 있다고 판단

**지하 계단**
- 중앙현관 근처 계단으로 가는 지하 진입로
- 구멍 뚫린 철판 셔터로 막혀 있고 자물쇠가 채워져 있음. 자물쇠에 "지하 계단" 스티커
- 주인공은 지하 계단 열쇠가 필요하다고 판단

**괴담코인**
- 퀘스트 보상으로 받는 재화

**경비**
- 교실 탈출 제한 시간이 끝나면 복도에서 다가오는 인물
- 푸른 제복, 모자, 손전등. 붉게 충혈된 푸른 눈
- 자물쇠를 열고 교실에 들어오며, 팔다리가 비정상적으로 꺾이거나 머리가 돌아가는 등 기괴한 움직임
- 중앙현관 쪽으로 가면 즉시 추적. 현관문을 쇠사슬로 봉쇄
- 붙잡히면 즉시 사망
- 청소도구함에 숨었을 때 소리에 반응해 수색하고, 위치가 들키면 발각·사망 이벤트

**진다연**
- 메인 히로인. 10년 넘게 학교에 갇혀 있던 인물
- 장난기 많고 요망한 성격. 동료로 들어올 때 특성이 "요망함", 칭호는 여고생귀신. 주인공의 공략 과정에서 단서 제시와 문제 해결을 맡음
- 3화에서 교실의 리코더 명찰에 이름이 나옴
