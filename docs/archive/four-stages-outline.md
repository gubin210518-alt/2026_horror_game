# 마지막 세이브 (가제) 개요서

공포 쯔꾸르풍 탈출 웹게임 장편 개요입니다. 목표 플레이타임은 90~120분이고, 챕터를 더하면 더 늘릴 수 있습니다.

## 0. 이 문서에 대하여

- 용도: Claude Code(Fable 5.2)로 실제 제작해보기 위한 장편 테스트 기획서
- 레퍼런스 방향: 웹소설/웹툰 『공포 쯔꾸르 생존기』의 큰 틀을 참고했습니다. "전설의 공포게임을 실행했더니 그 안에 갇혔다", "밤의 학교에서 깨어난다", "시스템 메시지가 탈출을 강요한다", "오래 갇혀 있던 인물을 만난다"는 장르적 뼈대만 가져왔습니다.
- 원작과의 거리: 인물, 게임 이름, 사건, 규칙, 결말은 모두 새로 만들었습니다. 원작의 장면이나 설정을 그대로 옮기지 않는 것이 원칙입니다. 나중에 공개 배포할 생각이면 이 원칙을 계속 지켜야 합니다.
- 기존 설정 연결: 앞서 정한 4개 배경(학교, 지하철, 폐가, 폐병원)을 그대로 챕터로 씁니다.

## 1. 한 줄 요약

인터넷에서 "끝까지 깬 사람이 없다"는 공포게임 `마지막 세이브.exe`를 실행한 주인공이, 다음 날 밤 텅 빈 학교에서 깨어나 게임의 규칙대로 네 개의 장소를 탈출해야 하는 이야기.

## 2. 세계관과 핵심 설정

### 2-1. 게임 속 게임: `마지막 세이브.exe`

- 2000년대 후반 개인 개발자가 만들다 사라졌다는 미완성 쯔꾸르 게임
- 실행하면 세이브 슬롯 4개 중 3개가 이미 차 있음. 날짜는 2009년, 2014년, 2019년
- 비어 있는 마지막 슬롯이 주인공의 자리
- 이 "세이브 슬롯"이 이야기 전체의 열쇠. 앞서 갇힌 세 사람의 흔적이 각 챕터에 남아 있음

### 2-2. 관리자

- 게임을 진행시키는 정체불명의 존재. 화면 위쪽 시스템 메시지로만 말함
- 말투는 친절한 튜토리얼처럼 정중하지만, 내용은 거짓이 섞여 있음
- 예시: `[관리자] 제한 시간 내에 출구를 찾아주세요. 플레이해주셔서 감사합니다.`

### 2-3. 괴담 규칙

- 각 챕터 시작 시 "규칙 카드"가 주어짐 (예: "복도에서 뛰지 마시오")
- 규칙 중 일부는 진짜, 일부는 관리자가 섞어 넣은 가짜
- 진짜 규칙은 앞선 갇힌 사람들의 메모로 검증할 수 있음
- 핵심 재미: "어떤 규칙을 믿을지" 플레이어가 판단하는 것

### 2-4. 주요 인물

| 인물 | 설명 |
|---|---|
| 한서진 (주인공) | 고2. 공포게임 실황을 즐겨 보는 평범한 학생. 성별은 정하지 않고 플레이어가 이입하기 쉽게 둠 |
| 윤하 | 2009년 세이브 슬롯의 주인. 교복 차림 그대로 학교에 남아 있음. 처음엔 길잡이 같지만 무언가를 숨김 |
| 2014년 슬롯의 주인 | 지하철 챕터에서 녹음 메시지와 낙서로만 등장. 탈출에 실패하고 규칙의 일부가 된 사람 |
| 2019년 슬롯의 주인 | 폐가 챕터의 가족 사진 속 인물과 연결. 관리자와 거래를 시도했던 흔적이 있음 |
| 관리자 | 게임을 굴리는 존재. 정체는 최종장에서 드러남 |

## 3. 전체 구조와 플레이타임

| 구간 | 장소 | 예상 시간 | 핵심 |
|---|---|---|---|
| 프롤로그 | 주인공의 방 → 학교 교실 | 5분 | 게임 실행, 교실에서 깨어남, 조작 튜토리얼 |
| 1장 | 학교 | 20~25분 | 윤하와 만남, 규칙 카드 첫 등장, 첫 추격 |
| 허브 | 세이브 룸 | 챕터 사이 1~2분 | 세이브 슬롯, 아이템 정리, 윤하와 대화 |
| 2장 | 지하철 | 15~20분 | 이상현상 찾기 루프, 2014년 슬롯의 흔적 |
| 3장 | 폐가 | 15~20분 | 숨바꼭질, 가족 사진 퍼즐, 2019년 슬롯의 흔적 |
| 4장 | 폐병원 | 20~25분 | 정신력과 빛 관리, 진료 기록 해독, 윤하의 비밀 |
| 최종장 | 뒤틀린 학교 | 10~15분 | 관리자와 대면, 엔딩 분기 |
| 합계 | | 약 90~120분 | 처음 플레이 기준. 수집 요소와 멀티엔딩으로 회차 플레이 유도 |

순서 메모: 2~4장은 허브에서 순서를 고를 수 있게 할 수도 있지만, 처음 만들 때는 고정 순서를 추천합니다. 이야기가 쌓이는 순서를 통제하기 쉽기 때문입니다.

## 4. 공통 시스템 (기믹)

웹서칭으로 확인한 공포게임 기믹 중 쯔꾸르 탑뷰에 잘 맞는 것들을 골랐습니다.

### 4-1. 숨기

- 사물함, 옷장, 침대 밑, 화장실 칸에 숨을 수 있음
- 숨은 동안 괴물이 가까이 오면 "숨 참기" 게이지가 등장. 길게 누르고 있다가 괴물이 멀어지면 뗌
- 같은 장소에 너무 자주 숨으면 괴물이 그곳을 먼저 확인하기 시작함 (반복 회피 방지)

### 4-2. 추격과 괴물 AI

- 평소에는 정해진 경로를 순찰
- 소리(뛰기, 문 세게 닫기, 물건 떨어뜨리기)가 나면 그 위치로 조사하러 감
- 플레이어를 발견하면 추격 시작. 시야에서 벗어나 숨으면 추격 해제
- 몸집 큰 괴물은 좁은 통로나 환기구에 못 들어감 → 레벨 디자인에서 "안전 통로"로 활용

### 4-3. 정신력 게이지

- 공포 이벤트를 보거나 어둠 속에 오래 있으면 감소
- 낮아질수록 화면 흔들림, 가장자리 어두워짐, 환청(가짜 발소리), 가짜 시스템 메시지 증가
- 0이 되면 게임 오버
- 회복: 안전한 장소(세이브 룸, 불 켜진 방)에서 쉬기, 윤하와 대화

### 4-4. 빛과 어둠의 줄다리기 (4장 중심)

- 손전등을 켜면 정신력이 유지되지만 괴물에게 잘 보임
- 끄면 숨기 쉽지만 정신력이 빠르게 감소
- 배터리는 한정되어 있어 계속 켜둘 수 없음

### 4-5. 괴담 규칙 카드

- 챕터마다 3~5장. 진짜와 가짜가 섞여 있음
- 규칙을 어기면 즉시 사망하는 것이 아니라 "벌칙 이벤트"(괴물 소환, 정신력 급감, 길 막힘)가 발동
- 수첩 화면에서 규칙을 모아 보고, 검증된 규칙엔 체크 표시

### 4-6. 아이템과 조합

- 인벤토리 칸 수를 제한해 무엇을 들고 갈지 고민하게 함
- 조합 예시: 건전지 + 빈 손전등, 찢어진 쪽지 두 장 → 완성된 메모

### 4-7. 시간 제한

- 일부 구간에만 "제한 시간"을 걺 (전부 걸면 피로함)
- 1장 마지막, 2장 루프 구간, 최종장에서 사용

### 4-8. 메타 연출 (쯔꾸르 공포 특유의 맛)

- 가짜 크래시: 화면이 멈추고 오류창이 뜨지만 실제로는 연출
- 세이브 파일 변조: 다시 불러오면 세이브 이름이 바뀌어 있거나 날짜가 2009년으로 표시됨
- 죽음의 기억: 게임 오버된 횟수를 윤하가 기억하고 언급함 ("방금 그 복도, 또 갔어?")
- 이름 호출: 시작 때 입력한 플레이어 이름을 관리자가 불러줌

### 4-9. 힌트

- 수첩의 "단서 정리" 메뉴에서 단계별 힌트 (1단계 방향 제시 → 2단계 위치 → 3단계 정답)
- 힌트를 쓴 횟수는 엔딩 화면 기록에만 반영하고 진행에는 불이익 없음

### 4-10. 접근성 옵션

- 숨 참기, 타이밍 입력의 판정 범위를 넓히는 "타이밍 보정" 옵션
- 깜짝 놀래기 연출 강도 조절, 화면 흔들림 끄기, 볼륨 분리 조절

## 5. 챕터별 상세

### 프롤로그: 다운로드 (5분)

1. 주인공의 방. 컴퓨터로 괴담 게시판을 보다 `마지막 세이브.exe` 링크를 발견
2. 실행하면 타이틀 화면에 세이브 슬롯 4개. 마지막 슬롯에 이름을 입력
3. 화면 암전 후, 다음 날 등교 장면을 짧게 보여줌 (평범한 하루)
4. 밤. 교실 책상에서 깨어남. 시계는 23:44. 교실 문이 잠겨 있음
5. 첫 시스템 메시지: `[관리자] 환영합니다, [플레이어 이름] 님. 출구를 찾아주세요.`

조작 튜토리얼은 이 교실 안에서 자연스럽게 진행합니다 (이동, 조사, 아이템 획득, 수첩 열기).

### 1장: 학교 (20~25분)

- 목표: 학교 밖으로 나가기
- 공간: 2학년 교실, 복도, 과학실, 방송실, 도서관, 현관
- 규칙 카드 예시
  - 진짜: "복도에서 뛰지 마시오"
  - 진짜: "방송이 나오면 가장 가까운 교실로 들어가시오"
  - 가짜: "도서관의 대출 기록을 보지 마시오" (실제론 핵심 단서가 있음)
- 흐름
  1. 교실 탈출: 칠판 낙서와 시간표로 사물함 번호를 알아내 교실 열쇠 획득
  2. 복도에서 윤하를 만남. 윤하는 "나도 갇혔어"라고만 말함
  3. 과학실: 약품장 순서 퍼즐로 방송실 열쇠 획득
  4. 방송실: 오래된 방송 기록에서 2009년 날짜의 안내방송을 들음. 윤하의 이름이 나옴
  5. 도서관: 가짜 규칙을 의심하고 대출 기록을 확인하면 앞선 갇힌 사람들의 이름 목록 발견
  6. 클라이맥스: 안내방송이 울리고 복도에 "순찰자"가 나타남. 현관까지 추격
  7. 현관을 나서면 바깥이 아니라 세이브 룸으로 이동
- 괴물: 순찰자 (손전등을 든 키 큰 경비원 실루엣, 얼굴이 없음)
- 챕터 끝 떡밥: 현관 앞에서 윤하는 따라 나오지 못하고 "나는 여기까지야"라고 말함

### 허브: 세이브 룸

- 하얀 방에 오래된 컴퓨터 한 대와 문 세 개
- 컴퓨터에서 세이브, 수첩, 아이템 정리 가능
- 챕터를 하나 깰 때마다 윤하가 세이브 룸에 잠깐 나타나 대화 (대화 선택지가 신뢰도에 영향)
- 세이브 슬롯 화면에 앞선 세 슬롯의 정보가 조금씩 열림

### 2장: 지하철 (15~20분)

- 목표: 끝나지 않는 역에서 빠져나가기
- 시작: 막차 안에서 깨어남. 내리면 같은 역이 반복됨
- 핵심 기믹: 이상현상 찾기 루프
  - 매 루프마다 역 이름, 안내방송, 벽시계, 광고판, 승객 중 하나가 미묘하게 달라짐
  - 이상현상이 있으면 뒤로 돌아가고, 없으면 앞으로 감
  - 정답을 연속으로 맞히면 다음 단계, 틀리면 처음부터
- 2014년 슬롯의 흔적
  - 벤치 밑 녹음기: 2014년 슬롯 주인의 음성 메모 ("나는 이상한 걸 너무 늦게 알아챘어")
  - 루프가 진행될수록 승강장의 낙서가 늘어남
- 규칙 카드 예시
  - 진짜: "같은 승객과 두 번 눈을 마주치지 마시오"
  - 가짜: "열차가 오면 반드시 타시오"
- 클라이맥스: 마지막 루프에서 승강장 끝 어둠 속의 존재가 다가옴. 반대편 열차 문이 닫히기 전에 탑승
- 괴물: 승강장 끝에 서 있는 긴 코트의 얼굴 없는 그림자
- 챕터 끝 떡밥: 녹음기 마지막 메시지에서 "관리자는 원래 우리 중 한 명이었어"라는 말이 끊김

### 3장: 폐가 (15~20분)

- 목표: 집 안의 "가족"이 다시 모이기 전에 탈출
- 공간: 거실, 복도, 부엌, 안방, 아이 방, 다락
- 핵심 기믹: 숨바꼭질
  - 귀신이 "술래" 역할로 숫자를 세며 집 안을 돌아다님 (숫자 세는 소리가 들림)
  - 숫자가 끝나기 전에 숨어야 하고, 숨은 사이에만 다음 방으로 이동 가능
  - 회차가 거듭될수록 숫자 세는 속도가 빨라짐
- 퍼즐
  - 가족사진 액자 4개의 순서 맞추기 (사진 속 인물이 한 명씩 사라져 있음)
  - 인형을 각 방의 원래 자리로 돌려놓기
  - 다락 잠긴 상자: 아이 방 일기의 날짜로 비밀번호 추리
- 2019년 슬롯의 흔적
  - 안방 서랍의 메모: 관리자와 "대신 남겠다"는 거래를 시도한 기록
- 규칙 카드 예시
  - 진짜: "술래가 숫자를 셀 때는 움직이지 마시오"
  - 진짜: "인형과 눈을 마주치면 3초 안에 시선을 돌리시오"
  - 가짜: "다락에는 올라가지 마시오"
- 클라이맥스: 다락에서 마지막 단서를 얻는 순간 숨바꼭질이 아닌 진짜 추격으로 바뀜. 현관까지 도주
- 괴물: 긴 검은 머리로 얼굴을 가린 흰 옷의 귀신
- 챕터 끝 떡밥: 가족사진의 마지막 액자에 윤하가 찍혀 있음

### 4장: 폐병원 (20~25분)

- 목표: 병원 지하의 "기록 보관실"에 도달
- 공간: 로비, 진료실, 병동 복도, 약품 창고, 수술실, 지하 기록 보관실
- 핵심 기믹: 빛과 정신력 관리
  - 손전등 배터리가 귀하고, 어둠 속에 오래 있으면 정신력이 빠르게 감소
  - 괴물은 빛에 반응해 다가옴
  - 불을 켤 수 있는 방(배전반 퍼즐)을 확보해 쉼터로 삼는 것이 공략 포인트
- 퍼즐
  - 진료 기록 해독: 환자 번호와 병실 번호의 규칙 찾기
  - 약품 조합: 라벨 색과 처방전의 기호를 대응시켜 진정제 만들기 (괴물을 잠시 멈추는 아이템)
  - 배전반: 정해진 순서로 차단기 올리기
- 윤하의 비밀
  - 기록 보관실에서 2009년 입원 기록 발견. 윤하는 게임 밖 현실에서 지금도 깨어나지 못한 채 입원해 있음
  - 즉, 윤하는 유령이 아니라 "아직 돌아갈 수 있는 사람"
- 규칙 카드 예시
  - 진짜: "호출벨이 울리면 대답하지 마시오"
  - 가짜: "수술실의 불은 절대 켜지 마시오" (켜야 진행 가능, 대신 괴물이 깨어남)
- 클라이맥스: 수술실 불을 켜면 괴물이 깨어나 기록 보관실까지 추격
- 괴물: 링거대를 끌고 다니는 마른 환자복 형체 (끄는 소리로 위치 파악 가능)

### 최종장: 뒤틀린 학교 (10~15분)

- 세이브 룸의 컴퓨터가 고장 나며 1장의 학교로 돌아감. 하지만 구조가 뒤틀려 있음
- 앞의 세 괴물이 모두 학교에 등장 (각자 기믹을 유지한 채 짧게 재등장)
- 관리자의 정체: 2009년 이전, 이 게임을 만들던 개발자. 미완성 게임을 "완성"시키기 위해 플레이어를 가둬 테스트를 반복시켜 옴
- 마지막 퍼즐: 앞 챕터에서 모은 진짜 규칙만 골라 순서대로 입력해야 마지막 문이 열림 (가짜 규칙을 섞으면 실패)

## 6. 엔딩 분기

| 엔딩 | 조건 | 내용 |
|---|---|---|
| 진엔딩: 함께 로그아웃 | 윤하 신뢰도 높음 + 진짜 규칙 전부 수집 + 4장에서 윤하의 기록 확인 | 주인공과 윤하가 함께 게임 밖으로. 병원에서 윤하가 깨어났다는 뉴스로 마무리 |
| 노말 엔딩: 혼자 탈출 | 진짜 규칙만 입력했지만 신뢰도가 낮거나 윤하 기록 미확인 | 주인공만 현실로 돌아옴. 컴퓨터에 `마지막 세이브.exe`가 다시 깔려 있음 |
| 배드 엔딩: 다섯 번째 슬롯 | 최종 퍼즐에 가짜 규칙을 섞음 | 주인공이 관리자의 자리를 이어받음. 타이틀 화면의 세이브 슬롯이 5개로 늘어 있음 |
| 히든 엔딩: 완성 | 진엔딩 조건 + 수집 요소(앞선 세 사람의 유품) 전부 | 개발자의 미완성 게임을 "끝내는" 선택. 타이틀 화면이 바뀜 |

회차 요소: 엔딩을 볼 때마다 타이틀 화면이 조금씩 달라지고, 2회차에는 윤하의 대사가 일부 바뀝니다.

## 8. 웹게임 구현 메모 (Claude Code 작업용)

- 기술: HTML + Canvas + JavaScript, 빌드 도구 없이 시작 가능한 구조
- 타일 기반 탑뷰, 48px 또는 32px 그리드
- 캐릭터: 쯔꾸르식 3칸 x 4줄 걷기 시트
- 데이터 분리: 맵, 이벤트, 대사, 규칙 카드는 JSON으로 분리해 기획 수정이 코드 수정 없이 가능하게
- 상태 관리: 플래그(스위치), 변수, 인벤토리, 정신력, 신뢰도
- 세이브: 브라우저 저장소(localStorage) 사용, 실패해도 게임은 진행되게 예외 처리
- 사운드: 발소리, 숫자 세는 소리, 링거대 끄는 소리처럼 "위치를 알려주는 소리"가 중요하니 거리별 볼륨 감쇠 구현
- 제작 순서 추천
  1. 엔진 뼈대: 이동, 충돌, 대화창, 조사, 맵 전환
  2. 공통 시스템: 인벤토리, 수첩, 규칙 카드, 힌트, 세이브
  3. 프롤로그 + 1장 (가장 많은 시스템을 쓰는 챕터라 시험대로 적합)
  4. 숨기와 추격 AI 다듬기
  5. 2장 루프 시스템 → 3장 숨바꼭질 → 4장 빛과 정신력
  6. 최종장과 엔딩 분기
  7. 메타 연출, 접근성 옵션, 테스트

## 9. 이미지 목록 (나노바나나/Higgsfield용)

기존에 정리한 공통 스타일 프롬프트를 그대로 사용합니다.

- 캐릭터 시트: 주인공, 윤하, 순찰자, 지하철 그림자, 폐가 귀신, 폐병원 환자
- 배경: 주인공 방, 교실, 학교 복도, 방송실, 도서관, 세이브 룸, 지하철 승강장, 폐가 거실·복도·안방·다락, 병원 로비·병동 복도·수술실·기록 보관실, 뒤틀린 학교
- 오브젝트 시트: 학교 소품, 지하철 소품, 폐가 소품, 병원 소품, 아이템 아이콘(열쇠, 건전지, 손전등, 녹음기, 진정제, 유품 3종)
- 얼굴 초상화(대화창용): 주인공, 윤하 (기본, 놀람, 슬픔 표정)
