# 마지막 세이브: 학교편 (가제) 개요서

학교 하나만 무대로 한 공포 쯔꾸르풍 탈출 웹게임 장편 개요입니다. 목표 플레이타임은 처음 플레이 기준 110~130분입니다.

## 0. 이 문서에 대하여

- 용도: Claude Code(Fable 5.2)로 실제 제작해보기 위한 장편 테스트 기획서
- 스토리라인: 연님이 나중에 다시 손볼 예정인 임시 초안입니다. 구조와 기믹을 먼저 보시라고 넣어둔 것입니다.
- 참고한 작품과 거리
  - 『공포 쯔꾸르 생존기』: "공포게임을 실행했더니 밤의 학교에 갇히고, 오래 갇혀 있던 학생을 만난다"는 장르 뼈대만 참고했습니다. 시스템 메시지로 탈출을 강요하는 관리자 장치는 쓰지 않습니다.
  - 『44교시 생존수업』: 학교 전체가 다른 공간에 삼켜지는 설정, 구역마다 다른 괴물, 먼저 살아남은 사람이 남긴 생존법, 함께 갇힌 학생들 사이의 협력과 불신이라는 방향만 참고했습니다.
  - 인물, 사건, 규칙, 반전은 모두 새로 만들었습니다. 연님이 스토리를 다시 짤 때도 원작의 장면이나 인물을 그대로 옮기지 않는 것을 권합니다.

## 1. 한 줄 요약

"끝까지 깬 사람이 없다"는 공포게임 `마지막 세이브.exe`를 실행한 다음 날 밤, 주인공은 텅 빈 학교에서 깨어납니다. 학교는 층마다, 특별실마다 다른 괴담 규칙으로 뒤틀려 있고, 주인공은 함께 갇힌 학생들과 규칙을 검증하며 출구를 찾아야 합니다.

## 2. 핵심 설정

### 2-1. `마지막 세이브.exe`

- 2000년대 후반 개인 개발자가 만들다 사라진 미완성 쯔꾸르 게임
- 타이틀의 세이브 슬롯 4개 중 3개가 이미 차 있음 (2009년, 2014년, 2019년)
- 앞서 갇힌 세 사람의 흔적이 학교 곳곳의 특별실에 나뉘어 남아 있음

### 2-2. 힌트로 진행하는 구조 (관리자 없음)

- 게임을 지시하는 존재는 없습니다. 플레이어는 학교 곳곳의 힌트를 읽고 스스로 다음 할 일을 알아냅니다.
- 힌트를 얻는 곳
  - 낙서: 책상, 칠판, 화장실 벽, 사물함 안쪽. 앞서 갇힌 사람들이 남긴 짧은 메모
  - 쪽지와 생존 수첩: 2009년 슬롯 주인이 남긴 기록. 퍼즐의 방향과 진짜 규칙을 알려줌
  - 학교 게시물: 시간표, 가정통신문, 공지문, 대출 기록처럼 원래 학교에 있는 물건
  - 동료의 말: 윤하, 민재, 아린이 상황을 보고 한마디씩 거듦
  - 환경 변화: 교시가 바뀌면 불이 켜지거나 문이 열리는 등 갈 곳이 눈에 보이게 바뀜
- 단계별 힌트: 일기장의 "단서 정리" 메뉴에서 막힌 퍼즐의 힌트를 1단계(방향) → 2단계(위치) → 3단계(정답) 순서로 볼 수 있습니다.
- 현재 목표 표시: 일기장 첫 장과 상태창에 "지금 해야 할 일"이 한 줄로 적혀 있고, 단서를 찾을 때마다 주인공의 메모 말투로 갱신됩니다. (예: "교실 열쇠는 사물함에 있는 것 같다. 번호가 어디 적혀 있을 텐데.")
- 일기장을 얻기 전(첫 교실)에는 칠판 낙서와 책상 메모가 목표 안내를 대신합니다.

### 2-3. 교시 시스템

- 학교 시간이 "교시" 단위로 흐름. 1교시부터 시작해 교시가 넘어갈 때마다 학교 구조와 괴물 배치가 바뀜
- 교시 종이 울리면 지정된 장소(교실)에 있어야 하고, 쉬는 시간에만 자유롭게 이동 가능
- 교시가 바뀔 때 칠판에 새 규칙이 저절로 적히거나, 교내 방송에서 지직거리는 목소리로 새 규칙이 들림
- 이 시스템이 학교 하나로 긴 플레이타임을 버티게 하는 핵심. 같은 복도라도 교시마다 다른 위험이 있음

### 2-4. 괴담 규칙과 생존 수첩

- 구역마다 규칙이 적힌 게시물이 붙어 있음. 진짜와 가짜가 섞여 있음 (가짜는 학교 자체가 플레이어를 속이려고 만든 것)
- 2009년 슬롯 주인이 남긴 "생존 수첩"의 찢어진 페이지를 모으면 진짜 규칙을 검증할 수 있음
- 수첩 페이지는 특별실 곳곳에 흩어져 있음 (수집 요소이자 진행 핵심). 주운 페이지는 일기장 뒤쪽에 끼워져 언제든 다시 읽을 수 있음

### 2-5. 주요 인물 (임시)

| 인물 | 설명 |
|---|---|
| 한서진 (주인공) | 고2. 공포게임 실황을 즐겨 보는 평범한 학생. 성별은 정하지 않음 |
| 윤하 | 2009년 슬롯의 주인. 10년 넘게 학교에 갇혀 있음. 성격은 서글서글하고 장난기가 많으며 겁이 없고 요망함 (확정). 길잡이 같지만 무언가를 숨김 |
| 도민재 | 같은 반 학생. 그날 밤 함께 갇힘. 체육부, 행동이 빠르지만 성급함. 체육 구역에서 활약 |
| 서아린 | 옆 반 학생. 함께 갇힘. 컴퓨터를 잘 다루고 의심이 많음. 학교 게시물의 규칙들을 비교해 진짜와 가짜를 가려내려 함 |

동료 시스템: 민재와 아린은 특정 구역에서 동행하며, 플레이어의 선택에 따라 신뢰도가 오르내립니다. 신뢰도가 낮으면 다툼 끝에 따로 행동하다 위험에 빠지는 이벤트가 생깁니다.

### 2-6. 상태창과 인벤토리 (확정)

- 관리자는 없지만, 상태창과 인벤토리는 둡니다.
- 상태창에 표시할 것
  - 정신력 게이지
  - 현재 교시
  - 현재 목표 한 줄
  - 보유 잉크 개수
  - 동료 상태 (함께 있는지, 신뢰도는 숨김 처리 추천)
- 인벤토리
  - 칸 수 제한 (무엇을 들고 갈지 고민하게 함)
  - 아이템 조사(설명 읽기), 사용, 조합
  - 일기장은 칸을 차지하지 않는 고정 아이템

### 2-7. 체크포인트: 일기장과 잉크 (확정)

- 일기장
  - 게임 시작 교실 다음으로 가는 교실에서 얻음
  - 얻은 뒤 게임이 끝날 때까지 계속 사용 가능
  - 잉크를 써서 일기를 쓰면 그 자리가 체크포인트가 됨
  - 목표 메모, 단서 정리, 단계별 힌트도 일기장에 모음
- 잉크
  - 특정 교실마다 놓여 있음
  - 일회성. 일기를 한 번 쓰면 한 병이 사라짐
  - 첫 잉크는 미술실(윤하와의 첫 만남 장면)에서 얻음
- 확정
  - 일기를 한 번도 안 쓰고 죽으면 첫 교실부터 다시 시작
  - 잉크는 되도록 적게 줌
  - 들고 다닐 수 있는 잉크 개수에 상한은 일단 두지 않음
- 제안
  - 죽으면 마지막으로 일기를 쓴 곳에서 다시 시작
  - 전체 잉크 수는 2시간 분량에 6~8병 정도. 한 막에 1~2병꼴
  - 잉크 위치는 어려운 구간 직전보다 조금 앞에 둬서 "지금 쓸지, 아껴둘지"를 고민하게 함
- 미정
  - 일기를 쓸 수 있는 장소를 제한할지(책상이 있는 곳만), 어디서나 쓸 수 있게 할지

## 3. 학교 지도

| 구역 | 층 | 포함된 공간 |
|---|---|---|
| 본관 | 1층 | 현관, 행정실, 교무실1, 보건실, 매점, 급식실 |
| 본관 | 2층 | 2학년 교실들, 미술실, 비품실, 교무실2, 상담실, 화장실 |
| 본관 | 3층 | 3학년 교실들, 교무실3, 도서관(제1·제2 비밀서고 포함), 시청각실 |
| 특별동 | 1층 | 과학실, 과학 준비실, 교무실4, 가사실 |
| 특별동 | 2층 | 컴퓨터실, 방송실, 교무실5, 미술 준비실 |
| 특별동 | 3층 | 음악실, 음악 준비실, 교무실6, 학생회실 |
| 체육 구역 | 별관 | 체육관, 체육창고, 교무실7, 탈의실 |
| 지하 | 지하 1층 | 보일러실, 창고 |
| 옥상 | 본관 위 | 옥상, 물탱크실 |

- 본관과 특별동은 2층 연결 복도로 이어짐. 체육관은 1층 뒷문으로만 갈 수 있음
- 교무실은 하나가 아니라 구역별로 교무실1~8까지 있음 (확정: 연님 학교처럼 여러 개)
  - 위 배치(교무실1~7)는 임시안이고, 교무실8은 위치 미정. 실제 학교 배치를 알려주시면 맞춰서 수정
  - 제안: 교무실8은 지도에 표시되지 않는 숨겨진 교무실로, 최종장 직전에만 열림
- 처음엔 본관 2층만 열려 있고, 진행에 따라 구역이 하나씩 열림 (메트로배니아식 구조)
- 미술실은 첫 진행 지점이라 시작 교실 가까이, 본관 2층으로 옮김 (특별동 2층에는 미술 준비실만 남김)
- 이미 지나온 구역도 교시가 바뀌면 새 위험과 새 단서가 생겨 되돌아갈 이유가 생김

## 4. 전체 구성과 플레이타임

| 막 | 교시 | 구역 | 예상 시간 |
|---|---|---|---|
| 프롤로그 | 0교시 | 주인공 방 → 2학년 교실 | 5분 |
| 1막 | 1~2교시 | 본관 1~2층 (미술실, 비품실, 교실, 매점, 보건실, 교무실1) | 30~35분 |
| 2막 | 3~4교시 | 특별동 (방송실, 컴퓨터실, 과학실, 가사실) | 25~30분 |
| 3막 | 5교시 | 체육 구역 (체육관, 체육창고, 탈의실) + 음악실 | 20~25분 |
| 4막 | 6교시 | 본관 3층 (도서관, 시청각실, 상담실) + 지하 보일러실 | 20~25분 |
| 최종장 | 7교시 | 뒤틀린 학교 전체 → 옥상 | 10~15분 |
| 합계 | | | 약 110~135분 |

## 5-0. 확정된 진행 순서 (연님 설계, 최우선)

아래 순서가 연님이 직접 설계한 확정 흐름입니다. 5장의 막별 상세는 이전 초안이라, 이 흐름에 맞춰 재배치가 필요합니다.

| 순서 | 장소 | 핵심 |
|---|---|---|
| 1 | 시작 교실 | 게임 시작, 조작 튜토리얼 |
| 2 | 옆 교실 | 일기장 획득 |
| 3 | 미술실 | 창문 속 윤하, 첫 잉크, <가란델가의 자매들>, 물감칼 |
| 4 | 비품실 | 이네스를 찌르면 열림 |
| 5 | 도서관 | 윤하와 대화, 제1·제2 비밀서고, 대칭 방 퍼즐 |
| 6 | 도서관 → 과학실 | 경비에게 잡혀 끌려감, 과학실 열쇠, 추격 |
| 7 | 과학실 | 인체 모형 맞추기 시작, 심장, 실험실 열쇠 |
| 8 | 실험실 | 윤하의 장난, 폐, <제물의 일기장>, 붉은 형체 추격, 황산 탈출 |
| 9 | 과학실 → 환풍구 | 환풍구 이동, 촉수, 창자 |
| 10 | 졸업사진 촬영 장소 | 다음 스테이지 (미정) |

### 도서관 (확정)

**공간**
- 비정상적으로 높은 책꽂이들과 비정상적으로 넓은 공간
- 제안: 책장이 화면 위로 끝없이 이어지게 보이고, 걸을 때 발소리가 길게 울리는 연출

**윤하와의 대화**
1. 도서관에서 윤하를 다시 만남 (미술실에서는 도망갔던 윤하와 처음으로 제대로 대화)
2. 이런저런 대화 끝에 윤하가 이곳에 10년 넘게 갇혀 있었다는 사실을 알게 됨
3. 이후 윤하가 동행. 함께 도서관을 이동

**비밀서고 입구**
1. 도서관을 이동하다 특정 책을 누르면 책장이 양옆으로 벌어지며 문 두 개가 나타남
2. 문 위의 글귀: "둘이 하나가 되는 순간, 문이 열릴 지어다"
3. 두 문에는 각각 [제1비밀서고], [제2비밀서고]라고 적혀 있음
4. 윤하가 혼자 열면 안 열림
5. 플레이어와 윤하가 동시에 열면 열림
   - 구현 제안: 플레이어가 한쪽 문 앞에서 조사하면 윤하가 다른 문 앞으로 이동하고, 짧은 연출 후 동시에 열림
   - 미정: 특정 책은 어떻게 찾게 할지 (예: 책 제목 힌트, 윤하가 알려주기, 하나만 빛바랜 책)

**대칭 방 퍼즐**
1. 문을 열고 들어가면 두 방이 나란히 있음. 가운데는 유리벽으로 뚫려 있어 서로 보임
   - 윤하의 방: 정리되어 있음
   - 플레이어의 방: 구조는 똑같지만 어지럽혀져 있음
   - 제안: 플레이어의 방을 프롤로그의 주인공 방과 똑같이 꾸미면 소름 포인트가 됨
2. 플레이어가 방에서 <읽으면 죽는 책>을 얻음
   - 붉은색 표지
   - 아이템 설명: "읽으면 죽는다"
3. 윤하가 유리를 노크하고 힌트 쪽지를 보여줌: "서로 마주보아라"
4. 클리어 조건: 어지럽혀진 플레이어의 방을 윤하의 방과 대칭이 되게 만들기
   - 핵심: 똑같이 만드는 게 아니라 좌우가 뒤집힌 거울상으로 만들어야 함 ("마주보아라")
   - 제안할 대칭 요소: 책장에 꽂을 책의 색 순서, 의자와 책상 위치, 커튼 열림 방향, 벽시계 바늘(거울상이라 3시는 9시로), 침대 이불
5. 함정: 책을 다 꽂고 대칭을 다 맞춰도 문이 안 열림. 벽에 걸린 액자 그림이 서로 다르기 때문
6. 해법: 윤하와 함께 액자를 뒷면으로 돌림. 뒷면은 서로 같아서 대칭이 완성되고 나갈 수 있음
   - 구현 제안: 플레이어가 액자를 돌리려 하면 "혼자서는 안 돌아간다"는 메시지, 윤하가 유리 너머로 자기 액자를 돌릴 때 같이 조사하면 성공

**경비에게 잡히는 장면**
1. 비밀서고를 나오면 바로 앞에 경비가 서 있음
2. 플레이어는 죽지 않음. 경비에게 잡혀 끌려가는 연출 (조작 불가 컷신)
3. 끌려가는 도중 경비의 허리춤에 걸린 열쇠 꾸러미가 보임
4. 그때 옆 책장이 무너지고, 플레이어는 열쇠 꾸러미에서 과학실 열쇠를 빼낸 채 풀려남
   - 미정: 열쇠를 뺏는 걸 자동 연출로 할지, 짧은 버튼 입력(QTE)으로 할지. QTE라면 판정을 넉넉하게
5. 경비는 잠깐 기절(스턴) 후 바로 추격 시작
6. 윤하와 함께 과학실까지 도망가야 다음 스토리가 진행됨
   - 제안: 이 추격이 게임 첫 추격전. 숨을 곳 없이 달리기만 하는 짧은 구간으로 해서 추격 연출을 체험시킴
   - 경비는 기존 설정의 "순찰자"와 같은 존재로 통일할지 미정

**아직 정하지 않은 것**
- <읽으면 죽는 책>의 용도 (나중 퍼즐에 쓰이는 핵심 아이템이 될지)
- 도서관에 잉크를 둘지 (경비 추격 직전이라 일기 쓸 기회를 줄지)
- 비품실 안에 무엇이 있는지, 비품실이 도서관으로 이어지는 통로인지
- 기존 초안의 도서관 기믹(소음 게이지, 사서)은 나중에 도서관에 다시 왔을 때 쓸지

### 과학실과 실험실 (확정)

**인체 모형 맞추기 (과학실의 가장 큰 이벤트)**
- 과학실의 인체 모형에 장기를 모두 채워 완성해야 함
- 장기는 맵 곳곳에 흩어져 있음. 지금까지 정해진 위치
  - 심장: 과학실 서랍 안
  - 폐: 실험실 전시장 위에서 떨어짐
  - 창자: 환풍구의 촉수를 잡아당겨서 얻음
- 미정
  - 나머지 장기 목록과 위치 (예: 뇌, 간, 위, 신장)
  - 모형이 과학실에 있는데 환풍구로 떠나므로, 장기를 다 모은 뒤 나중에 과학실로 돌아와 완성하는 구조인지
  - 모형을 완성하면 무엇이 일어나는지

**과학실 흐름**
1. 과학실 서랍에서 심장을 찾아 인체 모형에 넣음
2. 과학실을 돌아다니며 아이템을 챙길 수 있음. 여기서 <휴대용 황산>을 얻음
3. 좀 더 돌아다니면 윤하가 비커 안에서 실험실 열쇠를 발견함

**실험실 흐름**
1. 실험실 열쇠로 문을 열고 들어가면 문이 뒤에서 잠김
2. 윤하가 개구리 모형, 쥐 모형 등으로 장난을 침 (윤하의 장난기 많고 겁 없는 성격을 보여주는 장면)
3. 윤하의 장난을 피해 뒷걸음질 치다가 뒤쪽 전시장에 몸을 부딪힘
4. 그 충격으로 머리 위로 폐가 떨어짐 → 폐 획득
5. 바로 옆 전시장 안에 붉은 피부의 사람 형태가 들어 있고, 손에 종이를 쥐고 있음
6. 종이를 꺼내 보면 제목이 <제물의 일기장>

**<제물의 일기장> 내용 (연님 작성)**

> 19xx년 xx월 xx일
>
> 평소와 다를 바 없는 하루였다.
> 경균이 녀석이 뜬금없이 담력 체험을 하자고 했다. 사실 우리 학교가 몇십 년 전에는 공동묘지였다나 뭐라나.
>
> 나는 무서운 건 질색이라서 죽도록 가기 싫었는데 다른 친구들이 전부 찬성해서 강제로 가야 할 판국이다.
>
> 그날 배탈이라도 나면 좋겠다...

- 메모: 원문의 "공도묘지", "실헝ㅆ는데"는 오타로 보고 "공동묘지", "싫었는데"로 고침. 일부러 쓴 거라면 되돌리기

**붉은 형체 추격**
1. 일기장을 다 읽고 편지 창을 닫는 순간, 붉은 형체가 전시장 유리를 깨고 나옴
2. 추격 시작. 이 형체는 매우 느림
3. 실험실 문은 잠겨 있으므로, 과학실에서 챙긴 휴대용 황산으로 문손잡이를 녹여야 함
4. 녹이는 데 시간이 걸리고, 형체가 바로 뒤까지 쫓아왔을 때 문이 열림
5. 과학실로 뛰어 들어와 문을 닫으면 추격 종료

구현 메모 (제안)
- 황산을 안 챙기고 실험실에 들어가면 막힘(진행 불가)이 생김. 해결 방법 둘 중 하나
  - 황산을 챙겨야 실험실 열쇠 이벤트(윤하가 비커에서 발견)가 일어나게 순서를 묶음
  - 또는 실험실 안에도 황산을 하나 더 둠
- 녹이는 시간과 형체의 속도를 맞춰서 "아슬아슬하게" 열리도록 조정. 문 녹이는 동안 게이지를 보여주면 긴장감이 큼
- 일기장 내용(담력 체험, 학교 터가 공동묘지)은 학교가 사람을 가두는 이유와 이어질 떡밥. 제물의 일기장을 여러 장으로 나눠 다른 장소에도 두는 걸 제안

**환풍구 이동**
1. 추격이 끝나면 과학실 천장의 환풍구 뚜껑이 툭 떨어짐 → 환풍구로 다음 스테이지 이동
2. 환풍구를 기어갈수록 바닥이 점점 끈적해짐
3. 촉수 같은 것이 앞을 막음
4. 윤하는 먼저 통과하고 플레이어만 남겨짐
5. 윤하가 내민 손을 잡고 탈출
6. 그 촉수 같은 것을 잡아당기면 창자 획득
   - 미정: 창자를 얻는 게 탈출 전인지 후인지, 필수인지 선택인지

**다음 스테이지**
- 졸업사진 촬영하는 곳 (내용 미정)

## 5. 구역별 상세 (이전 초안)

각 구역은 "규칙, 기믹, 퍼즐, 괴물, 얻는 것" 순서로 정리했습니다.

### 프롤로그: 0교시 (5분)

1. 주인공의 방에서 괴담 게시판을 보다 `마지막 세이브.exe`를 실행. 빈 슬롯에 이름 입력
2. 다음 날 짧은 등교 장면 (평범한 교실, 민재와 잡담)
3. 밤. 교실 책상에서 깨어남 (확정: 게임은 교실에서 시작). 칠판 위 시계는 멈춘 채 0교시를 가리킴
4. 책상 위에 누군가 연필로 쓴 낙서: "7교시 끝나기 전에 나가. 옆 반 책상 서랍을 열어 봐."
5. 교실 안에서 조작 튜토리얼 진행 (이동, 조사, 아이템, 상태창)
6. 다음으로 들어가는 옆 교실 책상 서랍에서 일기장을 얻음 (확정). 일기장 첫 장에 첫 목표가 적힘
   - 이 시점엔 아직 잉크가 없어서 일기는 못 씀. "잉크가 필요하다"는 메모로 잉크의 존재를 알려줌
7. 교실에서 나오면 미술실로 가야만 진행됨 (확정)
   - 복도는 자유롭게 돌아다닐 수 있지만, 다른 교실은 잠겨 있거나 들어가도 이벤트가 일어나지 않음
   - 잠긴 문을 조사하면 짧은 혼잣말("잠겨 있다", "여긴 아무것도 없다")만 나와서, 플레이어가 자연스럽게 미술실로 향하게 함
   - 제안: 미술실 쪽 복도에만 불이 깜빡이게 해서 시선을 끌기

### 1막: 본관 1~2층 (1~2교시, 30~35분)

진행 순서: 5-0장의 확정 순서를 따름 (미술실 → 비품실 → 도서관 → 과학실). 아래 2학년 교실, 매점, 보건실, 교무실1은 이전 초안으로 재배치 필요

**미술실: 윤하와의 첫 만남과 <가란델가의 자매들> (확정)**

장면 흐름

1. 미술실 창문 너머로 윤하가 보임. 초상화처럼 꼼짝하지 않고 가만히 서 있음
2. 창문을 조사하면 윤하가 눈을 부릅뜨고 도망감
3. 창문 건너편으로 돌아가면 윤하가 서 있던 자리에 잉크 한 병이 있음 (첫 잉크)
4. 잉크를 줍는 순간 창문이 액자로 바뀜. 조사하면 "온기가 느껴진다"는 문구
5. 액자에는 그림이 걸려 있고, 제목은 <가란델가의 자매들>
6. 액자로 바뀐 걸 확인하면 액자에서 피가 흘러내리는 연출. 그 아래에 피로 글씨가 번져 나타남
   - "이들 중 가란델 가의 사람이 아닌 거짓말쟁이가 숨어 있다. 찾아서 죽여라."

거짓말쟁이 찾기 퍼즐

1. 액자를 한 번 더 조사하면 그림 속 인물들이 한 명씩 돌아가며 말함
   - 말풍선이 인물 위에 하나씩 뜨는 연출
2. 대사가 다 나오면 액자 테두리부터 피가 차오르기 시작함 (사실상 제한 시간)
3. 피가 그림을 다 덮으면 "누구를 죽이겠습니까?"라는 선택지가 뜸
4. 선택지에서 고르면 틀린 경우 액자 속으로 빨려 들어가 사망
5. 진짜 해법은 선택지가 아님 (선택지는 누구를 고르든 사망)
   - 미술실에서 물감칼(팔레트 나이프)을 찾아와 그림 속 거짓말쟁이를 직접 찌름
   - 찌르면 인물의 눈이 휘둥그레지며 비명을 지름 → 퍼즐 해결

대사 예시 (제안, 정답이 하나로 떨어지게 짠 논리 퍼즐)

- 규칙: 가란델 가의 자매는 진실만 말하고, 거짓말쟁이는 거짓만 말함. 거짓말쟁이는 한 명뿐
- 첫째 엘레나: "둘째 마리는 거짓말쟁이가 아니야."
- 둘째 마리: "거짓말쟁이는 셋째나 넷째 중에 있어."
- 셋째 로제: "첫째 언니는 진짜 가란델 가 사람이야."
- 넷째 이네스: "셋째 로제가 거짓말쟁이야."
- 정답: 넷째 이네스
  - 이네스가 거짓말쟁이일 때만 네 사람의 말이 모두 모순 없이 맞아떨어짐
  - 다른 사람을 거짓말쟁이로 두면 모순이 생기는 것도 검증함

연출 메모

- 피가 차오르는 동안 BGM이 점점 커지고, 그림 속 인물들의 눈이 플레이어를 따라 움직임
- 물감칼을 아직 안 가졌다면 피가 차오르기 전에 찾아와야 하므로, 칼은 미술실 안 눈에 띄는 곳(이젤 옆 물감통)에 둠
- 힌트: 피 글씨의 "죽여라"라는 표현, 그리고 미술실 칠판의 낙서 "고르지 마. 직접 해."
- 잉크를 이 퍼즐 직전에 주므로, 퍼즐 전에 일기를 쓰고 도전할 수 있음 (체크포인트 튜토리얼 역할)

확정 사항

- 선택지로 이네스를 골라도 실패. 선택지는 함정이고, 고르는 순간 누구를 고르든 액자 속으로 빨려 들어가 사망
- 정답은 오직 미술실의 물감칼로 이네스를 직접 찌르는 것
- 칼로 엉뚱한 인물을 찔러도 사망
- 이네스를 찌르면 액자 반대편 비품실 문이 열림

미정

- 기존 미술실 기믹(석고상 시선 기믹)은 미술 준비실이나 다른 교시로 옮겨서 유지할지
- 비품실 안에 무엇이 있을지

**2학년 교실과 복도**
- 규칙: "복도에서 뛰지 마시오" (진짜)
- 기믹: 교시 종과 쉬는 시간. 종이 울리면 30초 안에 아무 교실에나 들어가야 함
- 퍼즐: 시간표와 칠판 낙서로 사물함 번호 추리 → 교실 열쇠
- 괴물: 순찰자. 손전등을 든 얼굴 없는 경비원. 정해진 경로를 돌고 소리에 반응함
- 사건: 옆 교실에서 민재를 만남. 둘이 함께 행동 시작

**매점**
- 규칙: "매점의 물건은 값을 치르고 가져가시오" (진짜)
- 기믹: 거래. 계산대에 아무도 없지만 값을 안 내고 물건을 들고 나가면 매점 셔터가 내려오며 갇힘
- 퍼즐: 학교 곳곳에서 주운 동전과 학생증 포인트로 필요한 물건(건전지, 사탕, 손전등)을 삼. 무엇을 살지 고르는 자원 관리
- 얻는 것: 손전등, 건전지. 사탕은 정신력 회복 아이템
- 메모: 매점은 이후 교시마다 다시 들를 수 있는 "상점" 역할. 교시가 바뀌면 진열 상품이 달라짐

**보건실**
- 규칙: "보건 선생님이 부르면 침대에 누우시오" (가짜. 누우면 정신력 급감 이벤트)
- 기믹: 정신력 회복 장소. 단, 커튼 너머의 형체가 다가오는지 확인하며 쉬어야 함
- 퍼즐: 약품장의 약 이름과 학생 진료 일지의 증상을 대응시켜 진정제 조제
- 괴물: 커튼 뒤 보건 선생님 형체. 커튼을 걷지 않으면 공격하지 않음

## 9. 웹게임 구현 메모 (Claude Code 작업용)

- 기술: HTML + Canvas + JavaScript, 빌드 도구 없이 시작 가능한 구조
- 타일 기반 탑뷰, 32px 또는 48px 그리드, 쯔꾸르식 3칸 x 4줄 걷기 시트
- 데이터 분리: 맵, 이벤트, 대사, 규칙 카드, 교시별 괴물 배치를 JSON으로 분리
- 교시 시스템은 "현재 교시" 변수 하나로 맵 이벤트를 켜고 끄는 방식으로 구현
- 세이브: 일기를 쓸 때의 상태를 localStorage에 저장, 실패해도 진행되게 예외 처리
- 사운드: 위치를 알려주는 소리(발소리, 공 튀기는 소리, 피아노)가 중요하니 거리별 볼륨 감쇠 구현
- 제작 순서 추천
  1. 엔진 뼈대: 이동, 충돌, 대화창, 조사, 맵 전환
  2. 공통 시스템: 상태창, 인벤토리, 일기장과 잉크 체크포인트, 규칙 게시물, 교시
  3. 프롤로그 + 1막 2학년 교실과 복도 (시스템 시험대)
  4. 숨기와 순찰 AI
  5. 1막 나머지 → 2막 → 3막 → 4막 순서로 구역 추가
  6. 최종장과 엔딩 분기
  7. 메타 연출, 접근성, 전체 테스트
