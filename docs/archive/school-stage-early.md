# 학교 스테이지 개요서

공포 쯔꾸르풍 탈출 웹게임 중 "학교" 스테이지의 개요 초안입니다.

- 확정: 연님이 정한 내용
- 제안: Claude가 제안했고 아직 세부 확정이 안 된 내용
- 미정: 아직 정하지 않은 내용

## 1. 위치와 역할

- 확정: 학교는 폐병원과 함께 나중에 장편으로 확장할 스테이지입니다.
- 확정: 12/24 학교 축제 버전에는 학교를 넣지 않습니다. 축제 출품작은 지하철과 폐가입니다.
- 확정: 스테이지 하나의 기본 분량은 약 15분입니다.
- 제안: 학교의 첫 15분 버전을 장편의 "1장"으로 설계하고, 끝에서 이야기가 이어지는 여운을 남깁니다.
- 제안: 축제 버전의 허브 화면에서 학교 문은 "공사 중"으로 잠가 두어 확장판 예고로 씁니다.

## 2. 기본 설정

- 확정: 공포 스타일은 혼합형입니다. 평소에는 분위기 중심으로 가고, 클라이맥스에 추격이 들어갑니다.
- 제안: 야간자율학습이 끝난 뒤 혼자 학교에 남았는데 출입문이 잠겨 있는 상황에서 시작합니다.
- 제안: 공포의 핵심은 야간 순찰, 이상한 안내방송, 점점 가까워지는 발소리입니다.

## 3. 공간 (동선)

| 공간 | 역할 |
|---|---|
| 교실 | 시작 지점. 시간표와 칠판 낙서 같은 단서가 있음. 추격 때 숨는 장소 |
| 복도 | 순찰하는 존재가 돌아다니는 공간. 추격의 중심 |
| 방송실 | 열쇠로 진입. 암호를 입력하는 곳 |
| 현관 | 방송실 암호로 열리는 탈출구 |

## 4. 퍼즐 흐름 (제안)

1. 교실에서 시간표와 칠판 낙서를 조합해 사물함 번호를 알아냅니다.
2. 사물함을 열어 열쇠를 얻습니다.
3. 열쇠로 방송실에 들어갑니다.
4. 방송실에서 암호를 알아내 입력하면 현관이 열립니다.

단서의 구체적인 위치와 암호의 정답은 미정입니다.

## 5. 15분 흐름 (제안)

| 구간 | 시간 | 내용 |
|---|---|---|
| 도입 | 약 2분 | 혼자 남았고 출입문이 잠긴 것을 확인. 조작법 익히기 |
| 탐색과 퍼즐 | 약 8~10분 | 교실, 사물함, 방송실 순서로 퍼즐 진행. 분위기 연출은 이 구간에서 |
| 전환점 | 약 2분 | 안전하다고 믿던 공간이 깨지는 순간 (구체 연출 미정) |
| 추격 | 약 3~5분 | 복도를 순찰하는 존재를 피해 교실에 숨기 |
| 탈출과 엔딩 | 약 2분 | 현관 탈출 직전의 엔딩 연출 |

## 6. 공포 연출과 추격 (제안)

- 이상한 안내방송이 흘러나오고, 발소리가 점점 가까워집니다.
- 복도를 순찰하는 존재가 있고, 플레이어는 교실에 숨어서 피합니다.
- 추격, 숨기, 힌트는 다른 스테이지와 공용 시스템으로 만듭니다.

## 7. 엔딩 (제안)

탈출 직전에 출석부에서 사라진 학생들의 이름을 발견하고, 이야기가 이어지는 여운을 남기며 끝냅니다. 장편 확장판으로 이어지는 떡밥 역할입니다.

## 8. 제작 메모

- 확정: 웹게임(HTML/JS)으로 제작합니다.
- 확정: 이미지는 Higgsfield로 만들고, 크레딧이 모자라면 Claude가 준 프롬프트로 나노바나나에서 직접 만듭니다.
- 확정: 인물 스프라이트는 걷는 모션까지 한 장에 담은 쯔꾸르식 시트(가로 3칸, 세로 4줄)를 씁니다.
- 제안: 이미지 공통 스타일은 "16-bit top-down RPG pixel art, RPG Maker style, 3/4 overhead view, dark muted horror color palette, dim eerie lighting, crisp pixels, no text, no letters, no UI."를 쓰고, 첫 배경 이미지를 참고 이미지로 넣어 그림체를 통일합니다.
- 제안: 이미지 안의 글자는 AI 대신 게임 코드에서 직접 넣습니다.

## 9. 아직 정해지지 않은 것

- 순찰하는 존재의 정체와 외형
- 방송실 암호의 정답과 단서 배치
- 전환점의 구체 연출
- 사라진 학생들의 이야기 (장편에서 다룰 서사)
- 장편으로 확장할 때 추가할 구역
- 힌트 단계 구성
- 학교용 이미지 프롬프트 (배경, 오브젝트, 괴물 시트 모두 아직 안 만듦)
