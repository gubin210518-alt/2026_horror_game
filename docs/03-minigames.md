각 미니게임은 "목적, 규칙, 조작, 실패, 힌트, 구현 메모" 순서로 정리했습니다. 힌트는 일기장 "단서 정리"의 1단계(방향) → 2단계(위치) → 3단계(정답)입니다.

표기 규칙: "확정"은 연님이 정한 것, "제안"은 Claude가 채운 것.

## M0. 다운로드 강제 (확정)

- 목적: 플레이어가 "내가 이걸 받았다"는 찝찝함을 느끼게 함
- 규칙
  1. 게시글의 첨부 파일 `비현실.exe.zip`을 누르면 다운로드 창이 뜸 (버튼: 다운로드 / 취소)
  2. 취소 1회: 평범한 경고창 "파일을 받으시겠습니까?"
  3. 취소 2회: 문구가 이상해짐 "왜 안 받아요?"
  4. 취소 3회: 플레이어 이름을 부름. 이후 다운로드 버튼 외의 버튼은 커서가 다가가면 도망감
  5. 다운로드 → 압축 해제 진행 바 → 실행 → 화면이 꺼지며 1장
- 구현 메모
  - 모든 창은 게임 안에서 그린 가짜. 실제 파일 다운로드나 브라우저 알림창(alert)은 쓰지 않음
  - 플레이어 이름은 인트로 시작 전 입력받음 (예: 컴퓨터 로그인 화면에서 사용자 이름 입력)
  - 창 X를 누르면 창이 하나 더 복제되는 연출 (제안)

## M1. 사물함 배치표 (제안)

- 목적: 교실 탈출. 조작과 조사 튜토리얼 겸용
- 단서
  - 칠판 구석 낙서: "열쇠는 목요일 수학 시간 칸에"
  - 교실 앞 게시판 시간표: 목요일 3교시가 수학
  - 교실 뒤 사물함 벽: 가로 5칸(월~금) x 세로 7칸(1~7교시)으로 줄지어 있고, 옆에 "사물함은 시간표 모양대로"라는 배치표
- 정답: 목요일(4번째 열), 3교시(3번째 줄) 사물함 → 앞문 열쇠
- 실패: 틀린 사물함을 열면 안에서 손이 튀어나오는 깜짝 연출, 정신력 -10. 사망은 없음
- 힌트
  1. 칠판 낙서와 게시판을 같이 봐
  2. 사물함이 시간표처럼 생겼어
  3. 목요일 줄, 3교시 칸
- 구현 메모: 사물함 35개는 같은 이벤트를 복제하고 정답 1개만 다르게

## M2. 가란델가의 자매들 (확정)

- 목적: 윤하 첫 등장 이후의 첫 큰 퍼즐. "고르지 말고 직접 하라"는 함정 구조를 처음 체험
- 진행
  1. 액자를 조사하면 자매 4명이 한 명씩 말풍선으로 말함
  2. 대사가 끝나면 액자 테두리부터 피가 차오름 (제한 시간 60초, 제안)
  3. 피가 다 차면 선택지 "누구를 죽이겠습니까?" → 누구를 고르든 액자 속으로 빨려 들어가 사망 (확정)
  4. 정답: 미술실의 물감칼을 들고 액자 속 이네스를 조사 → 찌르기 (확정)
  5. 다른 인물을 찌르면 사망 (확정)
  6. 성공: 이네스의 눈이 휘둥그레지며 비명, 피가 빠지고 액자 반대편 비품실 문이 열림 (확정)
- 대사 (제안. 거짓말쟁이는 1명, 자매는 진실만, 거짓말쟁이는 거짓만)
  - 첫째 엘레나: "둘째 마리는 거짓말쟁이가 아니야."
  - 둘째 마리: "거짓말쟁이는 셋째나 넷째 중에 있어."
  - 셋째 로제: "첫째 언니는 진짜 가란델 가 사람이야."
  - 넷째 이네스: "셋째 로제가 거짓말쟁이야."
  - 정답 검증: 이네스일 때만 4명의 말이 모순 없이 성립. 엘레나, 마리, 로제를 거짓말쟁이로 두면 각각 모순 발생
- 물감칼 위치: 이젤 옆 물감통 (눈에 띄게)
- 힌트
  1. 피 글씨를 다시 읽어 봐. "고르라"가 아니라 "죽여라"였어
  2. 미술실에 날붙이가 있었던 것 같아
  3. 물감칼로 이네스를 찔러
- 미술실 칠판 낙서 (환경 힌트): "고르지 마. 직접 해."
- 구현 메모: 피 차오르는 동안에도 이동 가능해야 칼을 가지러 갈 수 있음. 대사는 일기장에 자동 기록되어 다시 볼 수 있게

## M3. 둘이 하나가 되는 순간 (확정)

- 규칙: 윤하 혼자 열면 안 열림. 플레이어와 윤하가 동시에 열어야 열림 (확정)
- 조작 (제안)
  1. 플레이어가 한쪽 문을 조사하면 선택지 "윤하에게 신호를 보낸다"
  2. 윤하가 다른 문 앞으로 이동, "셋 하면 열자. 하나, 둘…"
  3. "셋"에 맞춰 조사 버튼. 판정 범위 넉넉하게(앞뒤 0.7초), 접근성 옵션 켜면 자동 성공
- 실패: 윤하가 "너무 빨라!" 하고 다시 셈. 불이익 없음
- 비밀서고 입구 찾기 (미정이던 부분, 제안): 높은 책장 사이에 한 권만 거꾸로 꽂힌 책. 윤하가 "저건 내가 꽂은 거 아냐"라고 한마디

## M4. 마주보는 방 (확정)

- 구조: 같은 구조의 방 두 개, 가운데 유리벽. 윤하의 방은 정리됨, 플레이어의 방은 어지러움 (확정)
- 아이템: 플레이어 방에서 <읽으면 죽는 책> 획득. 붉은 표지, 설명 "읽으면 죽는다" (확정)
- 힌트 쪽지: 윤하가 유리를 노크하고 "서로 마주보아라" 쪽지를 보여줌 (확정)
- 클리어 조건: 플레이어 방을 윤하 방과 대칭으로 (확정). 똑같이가 아니라 좌우가 뒤집힌 거울상 (제안)
- 맞춰야 할 것 (제안, 6가지)
  1. 책장 책 5권 색 순서: 윤하 방 왼쪽부터 빨 주 노 초 파 → 플레이어 방은 왼쪽부터 파 초 노 주 빨
  2. 책상과 의자 위치: 쯔꾸르식으로 밀어서 이동
  3. 스탠드 위치: 책상 반대쪽 끝
  4. 커튼: 윤하 방은 오른쪽만 걷힘 → 플레이어 방은 왼쪽만 걷기
  5. 벽시계: 윤하 방 3시 → 플레이어 방 9시 (조사해서 바늘 돌리기)
  6. 바닥 쓰레기 3개 치우기 (윤하 방에는 없음)
- 함정: 다 맞춰도 문이 안 열림. 액자 그림이 서로 다르기 때문 (확정)
- 해법: 윤하와 함께 액자를 뒷면으로 돌림 (확정). 혼자 돌리려 하면 "혼자서는 안 돌아간다" → 윤하가 자기 액자를 잡을 때 같이 조사 (제안)
- 힌트
  1. "마주본다"는 건 거울처럼 보는 거야
  2. 윤하 방의 왼쪽은 네 방의 오른쪽이야
  3. 체크리스트 6개 표시 + 마지막엔 액자 뒷면
- 구현 메모: 6가지 상태를 플래그로 두고 하나 맞출 때마다 유리 너머 윤하가 엄지 척. 진행도가 보여야 막막하지 않음

## M5. 경비와 열쇠 꾸러미 (확정)

- 진행 (확정)
  1. 비밀서고를 나오면 경비가 서 있음. 플레이어는 죽지 않고 잡혀서 끌려감 (조작 불가 컷신)
  2. 끌려가는 중 경비 허리춤의 열쇠 꾸러미가 보임
  3. 옆 책장이 무너지며 풀려나고, 과학실 열쇠를 손에 넣음
  4. 경비는 잠깐 기절 후 추격. 윤하와 과학실까지 도망
- 열쇠 얻기 (제안): 기본은 자동 연출. 옵션으로 "열쇠 낚아채기" 버튼 입력(판정 넉넉) 추가 가능. 실패해도 책장이 무너질 때 열쇠가 바닥에 떨어져 자동 획득
- 첫 추격 (제안)
  - 숨을 곳 없는 일직선 복도 + 계단 + 복도 (약 20초)
  - 경비 속도는 플레이어 달리기보다 약간 느림. 장애물(넘어진 의자)에 부딪히면 잠깐 멈춤
  - 과학실 문에 닿으면 자동으로 들어가 문을 닫음
- 잡히면: 사망. 마지막 일기 위치에서 재시작 (도서관 비밀서고 입구 잉크를 쓰라는 유도)

## M6. 인체 모형 (확정, 게임 전체에 걸친 수집)

- 목적: 맵 곳곳의 장기를 모아 과학실 인체 모형을 완성 (확정)
- 장기 (위치는 `02-storyline.md` 표 참고): 심장, 폐, 창자 (확정) / 눈, 위, 간, 신장 2, 뇌 (제안). 총 9개
- 넣는 방법 (제안)
  - 모형을 조사하면 인체 도면 화면. 가진 장기를 끌어다 맞는 자리에 놓음
  - 틀린 자리에 놓으면 모형 고개가 플레이어 쪽으로 돌아감, 정신력 -5, 장기는 손으로 돌아옴
- 중간 보상 (제안): 장기 3개, 6개를 넣을 때마다 모형이 조금씩 움직여 다음 장소를 가리킴 (길잡이 역할)
- 완성 (제안, 9장): 모형이 일어나 옥상으로 걸어감
- 구현 메모: 장기는 일반 인벤토리가 아닌 "장기 주머니"에 보관해 칸 부족 문제 방지

## M7. 실험실 (확정)

**1단계: 윤하의 장난**
- 윤하가 개구리 모형, 쥐 모형을 들이밀며 장난 (확정)
- 조작 (제안): 윤하가 다가올 때마다 뒤로 물러나기 3번. 연출 위주, 실패 없음
- 3번째에 전시장에 부딪혀 폐가 떨어짐 → 폐 획득 (확정)

**2단계: 제물의 일기장과 붉은 형체**
- 옆 전시장 속 붉은 형체가 쥔 <제물의 일기장> 읽기 (확정)
- 편지 창을 닫으면 형체가 유리를 깨고 나와 추격 (확정). 속도는 플레이어 걷기의 절반 (제안)

**3단계: 황산으로 문 녹이기**
- 실험실 문은 들어올 때 잠김 (확정). 황산으로 문손잡이를 녹여야 함 (확정)
- 조작 (제안)
  - 문 앞에서 황산 사용 → "녹이는 중" 게이지 12초
  - 조사 버튼을 누르고 있는 동안만 게이지가 참. 떼면 멈추지만 줄어들지는 않음
  - 형체가 처음 위치에서 문까지 오는 데 약 13초 걸리게 배치 → 바로 뒤까지 왔을 때 열림 (확정 연출)
  - 실험실을 한 바퀴 돌며 형체를 따돌린 뒤 이어서 녹여도 됨
- 막힘 방지 (제안): 과학실에서 황산을 안 챙겼다면 실험실 개수대 아래에 예비 황산 1개
- 성공: 과학실로 뛰어 들어와 문을 닫으면 추격 종료 (확정)
- 실패: 잡히면 사망

## M8. 환풍구 (확정)

- 진행 (확정): 환풍구 뚜껑이 떨어짐 → 기어서 이동 → 바닥이 점점 끈적해짐 → 촉수가 앞을 막음 → 윤하는 먼저 통과 → 플레이어만 남음 → 윤하가 내민 손을 잡고 탈출 → 촉수를 당겨 창자 획득
- 조작 (제안)
  - 기어가기: 이동 속도 절반. 끈적한 구간에서 점점 더 느려짐 (시각적으로 바닥 색이 변함)
  - 촉수에 다리가 감김: "빠져나오기" 게이지. 버튼 연타(접근성 옵션: 길게 누르기) 로 채움
  - 게이지가 차는 동안 윤하의 손이 화면 위에서 내려옴. 손이 닿을 때 조사 → 탈출
  - 탈출 후 축 늘어진 촉수 조사 → "당긴다" → 창자 획득
- 실패 (제안): 게이지를 너무 늦게 채우면 촉수에 끌려가 사망. 판정은 넉넉하게

## M9. 졸업사진 자리 맞추기 (제안)

- 장소: 강당 무대의 단체사진 세트. 앞줄 의자 5개, 뒷줄은 서는 자리
- 단서
  - 벽의 얼굴 지워진 졸업사진 액자. 아래 명찰 자리에 이름 4개와 물음표 1개: 경균, 수정, 태호, 미란, ???
  - 무대 바닥에 흩어진 쪽지 조각 (<제물의 일기장> 2장의 뒷면 메모)
    1. "경균은 늘 그렇듯 한가운데"
