# 05. 구현 계획

기획 문서(`design/game-brief.md`)를 실제로 플레이 가능한 웹게임으로 만드는 계획입니다. 구현하면서 "제안" 내용을 바꾸면 맨 아래 "제안에서 바꾼 것"에 이유와 함께 적습니다.

## 1. 쓸 도구

2026-11-11 기준으로 확인한 결과입니다.

| 작업 | 쓸 것 | 메모 |
|---|---|---|
| 게임 코드 | HTML + Canvas + JavaScript(ES 모듈) | 빌드 도구, 외부 라이브러리 없음 |
| 로컬 실행 | `node server.js` 또는 `py -m http.server 8080` | 브라우저는 파일을 직접 열면(file://) 모듈과 데이터 불러오기를 막아서 로컬 서버가 필요함. 둘 중 아무거나 쓰면 됨 |
| 그림 | Higgsfield MCP | 연결은 무료지만 생성은 크레딧을 씀. 잔액 0.52, 무료 생성 불가 상태. 아래 3번 참고 |
| 소리 | Web Audio로 직접 합성 | 크레딧 0. 외부 소스를 쓰게 되면 `docs/credits.md`에 기록 |
| 실행 테스트 | `test/cdp.mjs` (화면 없는 Edge/Chrome을 띄워 실제 키 입력으로 조작) | Claude in Chrome 확장이 연결되어 있지 않아 직접 만듦. 의존성 없음 |
| 로직 테스트 | Node로 돌리는 작은 검사 스크립트 | 퍼즐 정답/오답, JSON 데이터 오류 확인 |
| 코드 점검 | code-review 스킬 | 5단계 통과 테스트 때 한 번 |
| 작업 방식 | ponytail 스킬(필요한 만큼만 만들기), task-observer 스킬(작업 중 개선점 기록) | 이미 켜져 있음 |

쓰지 않는 것: Figma, Lovable, Vercel, Netlify, Notion, Gmail 등. 배포는 요청받으면 그때 Vercel이나 Netlify로 합니다. Canva, Stitch는 인증이 안 되어 있어 못 씁니다 (필요 없음).

## 2. 구조

```
index.html
server.js              로컬 정적 서버
src/
  main.js              게임 루프, 화면 전환(타이틀, 인트로, 필드, 미니게임, 엔딩)
  engine/              입력, 맵과 충돌, 캐릭터와 추격 AI, 대화창, 이벤트 해석기,
                       메뉴(상태창, 인벤토리, 일기장, 옵션), 세이브, 소리
  minigames/           m0.js ~ m19.js (고유한 조작이 있는 것만 파일로)
data/
  maps/*.json          맵 타일, 충돌, 문, 이벤트 위치
  dialog.json          모든 대사
  items.json           아이템과 장기
  puzzles.json         퍼즐 정답, 제한 시간, 판정 범위, 힌트 3단계
  rules.json           규칙 카드 (진짜/가짜)
assets/                그림 (3단계부터)
test/                  검사 스크립트
```

- 화면: 내부 해상도 640x360, 타일 32px, 정수배 확대, 픽셀 그대로 표시
- 걷기 시트: 3칸 x 4줄 (아래, 왼쪽, 오른쪽, 위 순서). 이미지 크기에서 칸 크기를 자동 계산해서 쯔꾸르 규격 시트를 그대로 넣을 수 있게 함. `#00FF00` 배경은 불러올 때 코드로 지움
- 맵: 문자 격자 + 범례 형식의 JSON. 메모장으로 고칠 수 있게 함
- 이벤트: JSON 명령 목록(대사, 아이템 주기, 플래그, 조건, 맵 이동, 미니게임 시작). 대사와 정답을 고칠 때 코드는 안 건드림
- 세이브: 일기장 + 잉크 1개 → localStorage. 저장이 실패하면 안내만 띄우고 게임은 계속
- 접근성 옵션: 타이밍 판정 넓히기, 연타를 길게 누르기로, 깜짝 연출 강도, 화면 흔들림 끄기, 볼륨(배경음/효과음)
- M0: 캔버스 안에 그린 가짜 바탕화면. 실제 다운로드와 alert 없음

## 3. 그림 계획

Higgsfield가 무료인지 확인한 결과 (2026-11-11):

- MCP 연결 자체는 무료. 하지만 이미지 생성은 크레딧을 씀
- 이 계정은 무료 플랜, 잔액 0.52 크레딧
- "무제한 무료 생성"을 지원하는 모델(나노바나나 2, GPT Image 2 등)은 있지만, 이 계정에서는 꺼져 있음 (`unlim.available: false`). 무료 체험을 시작해야 켜지는 것으로 보이며, 체험 시작과 결제는 Claude가 하지 않음
- 연님이 직접 체험이나 크레딧을 켜면, 3단계에서 전부 Higgsfield로 만듦. 그 전에 목록과 예상 크레딧을 보여주고 허락을 받음

만드는 방식 (연님 지시):

- 캐릭터는 앞, 뒤, 옆 걷는 모션을 한 장(3칸 x 4줄)에 모두 넣어 뽑음. 같은 인물로 통일되게
- 공통 그림체 문구를 앞에 붙이고, 캐릭터와 오브젝트는 `#00FF00` 배경. 코드로 배경을 지움
- 크레딧이 끝내 없으면 같은 프롬프트를 `docs/asset-prompts.md`에 정리해 연님이 직접 만들 수 있게 함

단계별:

- 1~2단계: 색 도형 임시 그래픽
- 그림이 오기 전에도 게임이 볼 만하도록, 코드로 그린 간단한 픽셀 타일과 캐릭터를 기본값으로 둠
- 그림 속 글자(칠판 낙서, 액자 제목, 명찰 등)는 모두 코드로 그림

### 그래픽을 앞당긴 이유 (2026-11-12)

2단계 도중 연님이 "너무 허접해 보인다"고 해서, 3단계로 잡아 둔 그래픽 작업 일부를 2단계에 당겨 넣었습니다.

- 타일, 물건, 인물, 문을 코드로 그린 픽셀 아트로 교체 (`src/engine/art.js`)
- 밤 조명(플레이어 주변만 밝음), 깜빡이는 복도 형광등, 추격 중 붉은 가장자리
- 대화창 테두리와 초상화, 눈앞의 물건 이름표, 타이틀 화면, 합성 배경음(낮은 울림, 바람, 추격 중 심장 박동)
- 그림 파일을 넣으면 바로 바뀌는 자리: 걷기 시트 4장, 초상화 2장. 프롬프트는 `docs/asset-prompts.md`

3단계에 남은 것: 컷신, 효과음 다듬기, 큰 그림(타이틀, 자매 액자) 넣을 자리, `docs/credits.md`.

### 3단계 마무리 (2026-11-12)

- Higgsfield(GPT Image 2)로 그림 10장 생성: 걷기 시트 4, 윤하 초상화, 자매 액자, 타이틀 배경, 컷신 3 (창문 속 윤하, 경비, 유리를 깨는 붉은 형체). 크레딧 10을 모두 사용
- 컷신: 이벤트의 `picture` 명령으로 큰 그림을 띄우고 천천히 다가가는 움직임을 넣음. 세 장면에 연결
- 효과음 추가: 유리 깨짐, 비명
- 못 만든 그림과 프롬프트는 `docs/asset-prompts.md` 4번에 정리. 출처는 `docs/credits.md`
- 남은 것: 인트로 끝과 엔딩 컷신(엔딩은 4단계에서), 타일과 물건은 코드 그림 그대로

### 학교 구조 개편 (2026-11-12, 연님 지시)

- **ㅁ자형 2층**: 중정을 둘러싼 복도 한 장(`data/maps/floor2.json`). 교실은 복도 바깥쪽에만 있고 안쪽은 중정 창문. 처음부터 북, 동, 남쪽 복도를 자유롭게 걸을 수 있고, 서쪽 특별동은 방화 셔터로 막혀 있다가 경비 사건 때 열림
- **교실**: 문 두 개가 복도 쪽 벽(아래)에 있음
- **미술실**: 윤하는 복도에서 미술실 창문 너머로 보임. 안에 들어가면 그 창가에 잉크, 창문이 액자로 바뀜. 작업대, 이젤, 석고상 선반, 개수대, 건조대, 도구함으로 채움
- **비품실**: 양옆에 석고상. 온기가 느껴지는 석고상을 바닥의 금 간 망치로 깨면 도서관 열쇠 (연님 아이디어). 망치는 한 번 쓰면 부서지고, 차가운 석고상에는 쓰이지 않아 막히지 않음
- **과학실**: 교사용 실험대, 학생 실험대 6개, 약품장, 표본장, 개수대, 골격 모형, 현미경 등
- **지도**: 비품실 안내도를 얻으면 M 키로 그림 지도를 펼침 (`data/schoolmap.json`). 현재 위치 표시
- **M5 추격**: 별도 복도 맵 대신 실제 2층 복도(도서관 → 남쪽 복도 → 서쪽 복도 → 과학실)에서 진행. 경비는 넘어진 의자에 부딪히면 잠깐 멈춤. 끌려가는 중 "열쇠 낚아채기" 입력 추가 (실패해도 열쇠는 떨어짐)
- **인체 모형**: 모형 그림과 장기 아이콘으로 교체 (Higgsfield). 장기 3개, 6개를 넣으면 모형이 다음 장소를 가리킴
- 그 밖에 반영한 기획 내용: M3에서 윤하가 옆 문 앞으로 이동, M4 진행도 (n/6) 표시, 정신력 20 이하에서 가짜 낙서

기획에서 아직 구현하지 않은 것 (다시 읽고 확인한 목록):

- 손전등 배터리 (M18 보일러실과 매점 건전지에서 필요. 4단계에서)
- 숨을 곳(책상 밑, 사물함, 커튼 뒤 등)은 엔진에는 있지만 1~4장 맵에는 배치하지 않음. 순찰하는 괴이가 5장 이후에 나오기 때문
- M8에서 윤하의 손이 화면 위에서 내려오는 그림 연출 (지금은 글과 키 입력)
- 힌트 사용 횟수의 엔딩 화면 표시, 모바일 조작

### 화면과 조작 다듬기 (2026-11-12, 연님 지시)

- **그림이 늦게 바뀌던 문제**: 시작할 때 맵과 그림을 모두 미리 불러옴 (불러오는 중 화면). 코드 그림이 잠깐 보였다가 바뀌는 일이 없음
- **오른쪽으로 걸을 때 떠 보이던 문제**: AI 시트의 칸이 정확한 격자가 아니라 옆줄 그림이 섞여 들어갔던 것. 빈 줄을 찾아 칸을 나누도록 고침. 4명 모두 12칸의 발끝이 바닥에 맞는 것을 확인
- **테이블 위 물건**: 실험대와 작업대 위의 물건을 상판 높이에 맞춰 그림
- **인벤토리**: 4 x 4 격자에 아이템 그림, 16칸. 장기 주머니를 없애고 장기도 일반 소지품에 들어감. 아이템 아이콘 12종 생성
- **가란델가의 자매들**: 연님이 만든 그림 8장 적용 (피가 차오르는 4단계, 찔린 모습 4장). 화면이 붉게 차오르던 효과는 없애고, 액자를 조사하면 그림이 크게 뜨며 남은 시간에 따라 피가 차오름. 찌를 인물은 그림에서 직접 누르거나 ←→ 와 Space 로 고름. 틀리면 비웃는 소리
- **인트로 컴퓨터**: 로그인 화면, 배경, 아이콘, 작업 표시줄, 시작 메뉴, 폴더와 파일(메모장, 사진 보기, 내 PC), 끌어 옮길 수 있는 창, 댓글이 달린 게시판. 시간표.txt 에는 목요일 3교시 수학이 적혀 있음 (M1 복선)
- **모바일**: 터치 기기에서 화면 단추가 나옴 (방향 패드, A, B, 달리기, 상태/가방/일기/지도). 인트로는 화면을 직접 눌러 조작. 세로로 들면 가로로 돌리라는 안내

### 두 번째 다듬기 (2026-11-12, 연님 지시)

- **미술실 액자**: 코드로 그린 작은 초상화 네 칸을 없애고, 실제 액자 그림을 벽에 크게 걺. 이를 위해 미술실을 남쪽 복도로 옮김 (복도 쪽 벽이 방의 위쪽 벽이 되어 가로로 긴 그림을 걸 수 있음). 비품실은 미술실 아래쪽
- **실험실**: 벽을 따라 표본. 윤하가 표본 선반을 오가며 병을 바꿔 들고 다가오고, 주인공은 윤하를 본 채로 뒷걸음질 (Space 를 누를 때마다 다음 동작). 붉은 형체는 세로로 긴 전시장 안에 서 있는 모습이 보임
- **환풍구**: 윤하가 실제로 옆을 지나 먼저 건너감. 촉수와 점액을 살색으로
- **과학실**: 골격 모형을 빼고, 인체 모형을 줄이고, 넣은 장기가 방에 있는 모형에도 바로 보이게
- **가방 단추**: 왼쪽 위. 누르면 소지품. 아이템을 얻으면 그림이 크게 떴다가 가방으로 날아 들어감
- **화면 누르기**: 대화 넘기기, 선택지, 사물함 칸, 인벤토리 칸, 그림 속 인물을 직접 누를 수 있음. 터치 기기에서는 화면 단추도 같이 나옴
- **소리**: 비웃는 소리와 윤하 목소리 10줄을 Higgsfield로 생성. 처음 목소리가 나이 들어 보인다는 의견으로 더 어리고 가는 목소리로 다시 만듦
- **인트로**: 연님 화면에서 잘라 낸 배경, 960x540 해상도로 촘촘하게(전체가 작아 보임), 잠금 화면식 로그인, 옛 쯔꾸르풍 게임 타이틀, 게시글 6개 모두 읽을 수 있음
- **긴 알림**: 줄을 바꿔 화면 안에 표시

### 모바일 최적화 (2026-11-12, 연님 지시)

휴대폰 크기와 터치 환경을 흉내 내서 확인한 문제와 고친 것:

- **불러오기**: 그림이 28.9MB라 시작이 오래 걸림 → 모두 WebP로 바꿔 1.9MB. 이 PC 기준 9.3초 → 0.6초. 초록 배경 그림은 배경을 미리 지워 투명 WebP로 저장
- **세로 화면**: "가로로 돌려 주세요" 안내로 막혀 있었음 → 게임 화면을 위에 붙이고 아래 빈 자리에 단추를 크게 배치. 가로, 세로 모두 플레이 가능
- **가로 화면**: 단추가 대화창을 가림 → 단추를 작고 투명하게, 화면 양옆으로. 대화 중에는 단추를 숨기고 화면을 누르면 넘어감. 메뉴 창에서는 방향과 A/B만 표시
- **맵에 들어갈 때 화면이 검게 남던 문제**: 들어가자마자 대사가 나오면 화면 밝아지기가 멈춰 있었음 → 대화 중에도 진행
- **인트로**: 터치 기기에서는 아이콘과 글자를 크게. 이름 입력 칸 글자를 16px 이상으로 (아이폰이 화면을 확대하지 않게)
- **소리**: 첫 터치에 소리를 켬

- **흰 방 창 너머 윤하**: 몸을 일으킴 → 돌아섬 → 방 안쪽으로 걸어감 → 걸어와서 다시 들여다봄. 뒷모습 그림이 없어 앞모습을 코드로 가려 씀 (크레딧 생기면 교체)
- **깨진 글씨**: 풀려난 뒤 윤하에게 묻는 장면과 `paper` 미니게임 (쪽지의 `glitch` 글자가 깨져 떨림). "윤하에게는 읽힌다"는 대사는 Claude 제안
- **졸업사진**: 새 그림, 제목 "졸업을 축하합니다!"와 이름을 명조체로, 크게 띄워 제목에서 가운데 사진으로 내려옴
- **2층 복도**: 2칸 → 3칸 (맵 50x31). 의자를 둘씩 엇갈리게 다시 배치. 좌표 옮김 규칙은 x+1(x≥3), +1(x≥43) / y+1(y≥3), +1(y≥25)
- **1층**: `floor1` (3칸 복도, 북쪽에 교무실 1·2, 보건실, 행정실, 매점. 남쪽에 중앙 현관), `store` (매점: 진열대, 계산대, 냉장고, 냉동고, 탁자, 동전 3개, 규칙 카드). 별실 뒷문 → 계단 → 1층. 임시 맵 `auditorium` 삭제
- 매점의 상점 기능과 이야기는 만들지 않음. 연님 기획을 받은 뒤 구현
- Higgsfield 0.5 크레딧 사용, 잔액 0.07
