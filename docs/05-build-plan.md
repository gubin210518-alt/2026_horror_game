# 05. 구현 계획

기획 문서(`design/game-brief.md`)를 실제로 플레이 가능한 웹게임으로 만드는 계획입니다. 구현하면서 "제안" 내용을 바꾸면 맨 아래 "제안에서 바꾼 것"에 이유와 함께 적습니다.

## 1. 쓸 도구

2026-11-11 기준으로 확인한 결과입니다.

| 작업 | 쓸 것 | 메모 |
|---|---|---|
| 게임 코드 | HTML + Canvas + JavaScript(ES 모듈) | 빌드 도구, 외부 라이브러리 없음 |
| 로컬 실행 | `node server.js` 또는 `py -m http.server 8080` | 브라우저는 파일을 직접 열면(file://) 모듈과 데이터 불러오기를 막아서 로컬 서버가 필요함. 둘 중 아무거나 쓰면 됨 |
| 그림 | Higgsfield MCP | 연결은 무료지만 생성은 크레딧을 씀. 잔액 0.52, 무료 생성 불가 상태. 아래 3번 참고 |
| 소리 | Web Audio로 직접 합성 | 크레딧 0. 외부 소스를 쓰게 되면 `docs/credits.md`에 기록 |
| 실행 테스트 | `test/cdp.mjs` (화면 없는 Edge/Chrome을 띄워 실제 키 입력으로 조작) | Claude in Chrome 확장이 연결되어 있지 않아 직접 만듦. 의존성 없음 |
| 로직 테스트 | Node로 돌리는 작은 검사 스크립트 | 퍼즐 정답/오답, JSON 데이터 오류 확인 |
| 코드 점검 | code-review 스킬 | 5단계 통과 테스트 때 한 번 |
| 작업 방식 | ponytail 스킬(필요한 만큼만 만들기), task-observer 스킬(작업 중 개선점 기록) | 이미 켜져 있음 |

쓰지 않는 것: Figma, Lovable, Vercel, Netlify, Notion, Gmail 등. 배포는 요청받으면 그때 Vercel이나 Netlify로 합니다. Canva, Stitch는 인증이 안 되어 있어 못 씁니다 (필요 없음).

## 2. 구조

```
index.html
server.js              로컬 정적 서버
src/
  main.js              게임 루프, 화면 전환(타이틀, 인트로, 필드, 미니게임, 엔딩)
  engine/              입력, 맵과 충돌, 캐릭터와 추격 AI, 대화창, 이벤트 해석기,
                       메뉴(상태창, 인벤토리, 일기장, 옵션), 세이브, 소리
  minigames/           m0.js ~ m19.js (고유한 조작이 있는 것만 파일로)
data/
  maps/*.json          맵 타일, 충돌, 문, 이벤트 위치
  dialog.json          모든 대사
  items.json           아이템과 장기
  puzzles.json         퍼즐 정답, 제한 시간, 판정 범위, 힌트 3단계
  rules.json           규칙 카드 (진짜/가짜)
assets/                그림 (3단계부터)
test/                  검사 스크립트
```

- 화면: 내부 해상도 640x360, 타일 32px, 정수배 확대, 픽셀 그대로 표시
- 걷기 시트: 3칸 x 4줄 (아래, 왼쪽, 오른쪽, 위 순서). 이미지 크기에서 칸 크기를 자동 계산해서 쯔꾸르 규격 시트를 그대로 넣을 수 있게 함. `#00FF00` 배경은 불러올 때 코드로 지움
- 맵: 문자 격자 + 범례 형식의 JSON. 메모장으로 고칠 수 있게 함
- 이벤트: JSON 명령 목록(대사, 아이템 주기, 플래그, 조건, 맵 이동, 미니게임 시작). 대사와 정답을 고칠 때 코드는 안 건드림
- 세이브: 일기장 + 잉크 1개 → localStorage. 저장이 실패하면 안내만 띄우고 게임은 계속
- 접근성 옵션: 타이밍 판정 넓히기, 연타를 길게 누르기로, 깜짝 연출 강도, 화면 흔들림 끄기, 볼륨(배경음/효과음)
- M0: 캔버스 안에 그린 가짜 바탕화면. 실제 다운로드와 alert 없음

## 3. 그림 계획

Higgsfield가 무료인지 확인한 결과 (2026-11-11):

- MCP 연결 자체는 무료. 하지만 이미지 생성은 크레딧을 씀
- 이 계정은 무료 플랜, 잔액 0.52 크레딧
- "무제한 무료 생성"을 지원하는 모델(나노바나나 2, GPT Image 2 등)은 있지만, 이 계정에서는 꺼져 있음 (`unlim.available: false`). 무료 체험을 시작해야 켜지는 것으로 보이며, 체험 시작과 결제는 Claude가 하지 않음
- 연님이 직접 체험이나 크레딧을 켜면, 3단계에서 전부 Higgsfield로 만듦. 그 전에 목록과 예상 크레딧을 보여주고 허락을 받음

만드는 방식 (연님 지시):

- 캐릭터는 앞, 뒤, 옆 걷는 모션을 한 장(3칸 x 4줄)에 모두 넣어 뽑음. 같은 인물로 통일되게
- 공통 그림체 문구를 앞에 붙이고, 캐릭터와 오브젝트는 `#00FF00` 배경. 코드로 배경을 지움
- 크레딧이 끝내 없으면 같은 프롬프트를 `docs/asset-prompts.md`에 정리해 연님이 직접 만들 수 있게 함

단계별:

- 1~2단계: 색 도형 임시 그래픽
- 그림이 오기 전에도 게임이 볼 만하도록, 코드로 그린 간단한 픽셀 타일과 캐릭터를 기본값으로 둠
- 그림 속 글자(칠판 낙서, 액자 제목, 명찰 등)는 모두 코드로 그림

### 그래픽을 앞당긴 이유 (2026-11-12)

2단계 도중 연님이 "너무 허접해 보인다"고 해서, 3단계로 잡아 둔 그래픽 작업 일부를 2단계에 당겨 넣었습니다.

- 타일, 물건, 인물, 문을 코드로 그린 픽셀 아트로 교체 (`src/engine/art.js`)
- 밤 조명(플레이어 주변만 밝음), 깜빡이는 복도 형광등, 추격 중 붉은 가장자리
- 대화창 테두리와 초상화, 눈앞의 물건 이름표, 타이틀 화면, 합성 배경음(낮은 울림, 바람, 추격 중 심장 박동)
- 그림 파일을 넣으면 바로 바뀌는 자리: 걷기 시트 4장, 초상화 2장. 프롬프트는 `docs/asset-prompts.md`

3단계에 남은 것: 컷신, 효과음 다듬기, 큰 그림(타이틀, 자매 액자) 넣을 자리, `docs/credits.md`.

### 3단계 마무리 (2026-11-12)

- Higgsfield(GPT Image 2)로 그림 10장 생성: 걷기 시트 4, 윤하 초상화, 자매 액자, 타이틀 배경, 컷신 3 (창문 속 윤하, 경비, 유리를 깨는 붉은 형체). 크레딧 10을 모두 사용
- 컷신: 이벤트의 `picture` 명령으로 큰 그림을 띄우고 천천히 다가가는 움직임을 넣음. 세 장면에 연결
- 효과음 추가: 유리 깨짐, 비명
- 못 만든 그림과 프롬프트는 `docs/asset-prompts.md` 4번에 정리. 출처는 `docs/credits.md`
- 남은 것: 인트로 끝과 엔딩 컷신(엔딩은 4단계에서), 타일과 물건은 코드 그림 그대로

## 3-1. 컷신 (코드로 만드는 영상)

영상 파일을 만들지 않고, 게임 안에서 Canvas로 그리는 컷신으로 구현합니다. 3단계에서 작업합니다.

- 목적: 조작으로는 전달이 안 되는 순간을 보여주는 것. 플레이어가 직접 할 수 있는 장면은 컷신으로 만들지 않음
- 넣을 곳 (후보): ① 인트로 끝, 게임을 실행하면 모니터가 꺼지며 교실에서 깨어나는 전환 ② 윤하 첫 등장(창문 속에서 눈을 부릅뜨는 순간) ③ 경비에게 끌려가는 장면 ④ 붉은 형체가 유리를 깨고 나오는 순간 ⑤ 엔딩
- 방향: 짧게(5~15초), 넘길 수 있게, 깜짝 연출 강도와 화면 흔들림 옵션을 따름. 그림은 게임 그래픽을 그대로 확대하거나 큰 일러스트 한 장에 움직임(확대, 흔들림, 번쩍임, 글자)을 입힘

## 5. 연님 결정이 필요한 것

**지금 (1~2단계에 영향)**
- 없음. 확정 내용과 제안 기본값만으로 진행 가능합니다. 주인공 이름은 M0 확정 내용대로 로그인 화면에서 입력받습니다.

**연님이 정한 것 (2026-11-11)**
- 5장 이후는 `reference/original-notes.md`의 흐름(졸업 사진 → CCTV → 경비 → 2회차 → 최종전 → TRUE END)에 맞춰 Claude가 구성해서 구현. 구체적인 구성은 4단계 시작 때 이 문서에 적음
- <제물의 일기장> 2~4장 내용은 비워 둠. 연님이 나중에 `data/notes.json`에 채움

**아직 남은 것**
- 게임 제목 (그 전까지 타이틀 화면은 작중 게임 이름 `비현실`로 표시)

**알아둘 것**
- 1~4장 흐름이 웹소설 『공포 쯔꾸르 생존기』 챕터 1과 많이 겹칩니다 (`reference/original-notes.md` 대응표). 개인 작업이나 학교 과제로는 문제없지만, 인터넷에 공개 배포할 계획이면 겹치는 장면을 더 바꾸는 게 안전합니다.
