# 이어서 작업하는 세션을 위한 안내

다른 계정이나 새 세션에서 이 프로젝트를 이어 받을 때 읽는 문서다. `CLAUDE.md` 가 이 파일을 불러온다. 여기 적힌 것은 연님이 실제로 준 피드백과, 작업하면서 확인한 사실이다.

## 시작할 때

1. `git pull` 로 `dev/game-build` 를 맞춘다. 다른 세션이 올린 것이 있을 수 있다
2. `docs/05-build-plan.md` 의 맨 아래 변경 기록과 `design/game-brief.md` 에서 해당 장을 읽는다
3. `node server.js` 를 켜고 `node test/check-data.mjs`, `node test/stage2.mjs`, `node test/stage3.mjs` 가 통과하는 상태에서 시작한다
4. 연님이 준 기획(손글씨 사진, `docs/reference/`, `docs/archive/`)은 그대로 따른다. 읽기 어려운 글자나 이야기의 빈 곳은 지어내지 않고 묻는다

## 연님이 원하는 수준 (실제 피드백)

- **코드로 그린 그림은 싫어한다.** "허접하다", "밤티난다", "성의 없다"는 말이 나온 것은 전부 코드 그림이나 빈 방이었다. 눈에 띄는 물건, 인물, 컷신은 Higgsfield 그림으로 만든다. 코드 그림은 타일과 작은 소품에만 쓴다
- **방이 비어 있으면 안 된다.** 실제 그 교실에 있을 물건(과학실 실험대, 미술실 이젤, 준비실 표본)을 채운다. 학교 구조도 실제 학교처럼(ㅁ자 복도, 한쪽에만 교실)
- **연출은 겹쳐서 만든다.** 큰 그림 한 장에 인물까지 그려 넣지 말고, 배경 그림 + 인물 그림 + 틀을 따로 만들어 코드로 겹친다. 그래야 움직임을 넣고 고치기 쉽다 (예: 흰 방의 타원 창, `src/minigames/ch5.js` 의 `camWindow`)
- **말과 화면이 맞아야 한다.** "먼저 간다"고 하면 실제로 먼저 가야 하고, 뒷걸음질이면 등을 돌리지 않아야 한다. 대사를 쓰면 그 장면이 화면에서 일어나는지 직접 확인한다
- 화면을 가득 덮는 효과(피가 차오르는 색 덧칠 등)보다 그림 자체가 바뀌는 쪽을 좋아한다
- AI 티가 나는 배경은 싫어한다. 연님이 준 사진이나 캡처가 있으면 그것을 잘라 쓴다
- 윤하: 여리고 가는 10대 목소리, 장난스럽고 요망한 말투. 아줌마 같은 목소리는 안 된다 (프리셋 Pixie, pitch 1.2)
- 휴대폰으로도 한다. 모든 조작은 터치로도 되어야 하고, 글자는 화면 밖으로 나가면 안 된다
- 보고는 짧게. 무엇을 만들었고, 어떻게 보고, 연님이 정할 것이 무엇인지만. 보고 전에 반드시 push 한다

## 만들 때 지키는 것

- 기획의 숫자와 글은 `data/*.json` 에 둔다. 코드에 박지 않는다. 새 명령이나 미니게임을 만들면 `test/check-data.mjs` 의 목록에 추가한다
- 장면을 만들면 `test/stage*.mjs` 에 실제 키 입력으로 통과하는 검사를 넣고, 화면을 찍어 `production/qa/evidence/` 에 남긴 뒤 **직접 열어 본다**. 검사 통과만으로 끝내지 않는다. 그림이 어색하면 고친다
- 막힘 방지: 필요한 물건을 얻기 전에는 다음 맵으로 못 가게 하고, 실패하면 마지막 일기로 돌아가게 한다
- 코드는 짧게. 이미 있는 명령(`picture`, `move`, `npc`, `minigame` …)으로 되는 것은 새로 만들지 않는다

## 그림과 소리 만들기 (Higgsfield MCP)

- 먼저 `balance` 로 잔액을 본다. 무료 플랜이다. 유료 가입, 체험, 결제는 하지 않는다. 모자라면 연님에게 알린다
- 모델은 `gpt_image_2`. `quality:"low", resolution:"1k"` 가 0.5 크레딧, `medium` 이 1 크레딧이다. low 로도 충분했다. `get_cost:true` 로 미리 확인할 수 있다
- 한 번에 하나만 돈다. 하나 내고 `jobs_wait` 로 끝난 것을 확인한 뒤 다음 것을 낸다
- 프롬프트 앞에 붙이는 문구와 지금까지 쓴 프롬프트는 `docs/asset-prompts.md`. 인물과 물건은 `#00FF00` 단색 배경으로 뽑고, 그림 속 글자는 코드가 그린다
- 기존 그림을 고칠 때는 `media_upload` → curl PUT → `media_confirm` 으로 올린 뒤 `medias:[{role:"image", value:<id>}]` 로 참고시킨다. "이 부분만 초록으로 채워라" 같은 편집이 잘 된다
- 받은 PNG는 WebP로 바꿔 `assets/` 에 넣는다 (초록 배경은 이때 미리 지운다). 변환은 화면 없는 브라우저의 canvas 로 한다: `tools/to-webp.mjs`
- 목소리: `qwen_audio_tts`, 한 줄 0.01 크레딧, 한 번에 하나. 효과음: `mirelo_text_to_audio`
- 만든 것은 `docs/credits.md` 와 `docs/asset-prompts.md` 에 적는다
- 미성년 인물(윤하 등)을 성적으로 보이게 하는 구도는 만들지 않는다
- 2026-11-13 기준 잔액 0.07. 더 만들려면 연님이 다른 계정을 연결해야 한다. 그때 만들 것: 윤하의 뒷모습(흰 방 창 너머에서 걸어갈 때 쓰는 그림. 지금은 앞모습을 코드로 가려 쓰고 있다)

## 이 컴퓨터에서 걸리는 것들

- 파이썬은 `py` 로 부른다. 서버는 `node server.js`
- 커밋: `git -c user.name="gubin210518-alt" -c user.email="gubin210518@gmail.com" commit …` (git 설정은 건드리지 않는다). force push 금지, main 에 push 금지
- `rm -rf` 는 막혀 있다. 임시 폴더는 새 이름으로 만든다
- 문법 검사는 `.mjs` 로 복사한 뒤 `node --check`
- 따옴표가 섞인 긴 수정은 셸 한 줄로 하지 말고, 패치 스크립트를 파일로 써서 `node 스크립트 "$PWD"` 로 돌린다
- 크롬 확장은 연결이 안 될 때가 많다. 화면 확인은 `test/cdp.mjs` (화면 없는 Edge)로 한다
- 서버는 세션 사이에 꺼진다. `curl localhost:8080` 으로 확인하고 다시 켠다

## 이 계정에 깔려 있던 것 (다른 계정에도 깔면 같아진다)

저장소 안의 `.claude/` (에이전트, 스킬, 규칙)는 pull 하면 그대로 따라온다. 아래는 계정마다 따로 설치해야 하는 것이다.

| 종류 | 이름 | 하는 일 |
|---|---|---|
| 플러그인 | ponytail | 코드를 가장 짧고 단순하게 짜도록 강제 |
| 스킬 | task-observer | 작업 중 배운 것을 기록해 스킬을 고침 |
| 스킬 | graphify | 코드와 문서를 지식 그래프로 |
| 커넥터 | Higgsfield | 그림, 목소리, 효과음 생성 |
| 커넥터 | Vercel | 배포 확인 (프로젝트 `2026sj_hg`, 사이트 2026sjhg.vercel.app) |

모델은 가장 높은 등급(Fable/Opus급)으로 두는 것이 좋다. 낮은 모델로 이어 받은 세션에서 결과가 나빴다.
